# 머신러닝

#2026-07-30

---

컴퓨터를 작업하게 만드는 일반적인 방법은 데이터를 해답으로 바꾸는 규칙(프로그램)을 만드는 것이다. 

머신러닝은 데이터와 해답을 보고 규칙을 찾는다. 프로그램 되는게 아니라 훈련 된다. 데이터에서 통계적 구조를 찾아 작업을 자동화하기위한 규칙을 만든다.

머신러닝은 수리통계학과 연관되어있긴 하지만 통계학과 달리 대량의 복잡한 데이터를 쓰기때문에 베이즈 분석같은 전통적인 통계분석방법을 현실적으로 적용하기어렵다. 그래서 머신러닝, 딥러닝은 수학적 이론이 많이 부족하고 그래서 근본적으로 엔지니어링 분야이다.

머신러닝에는 세가지가 필요하다. 데이터, 기대 출력, 성능 측정 방법. (알고리즘 작동방식을 교정하는데 사용됨)

모델은 데이터를 의미있는 출력으로 변환한다. (기대 출력이랑 비교용) 그래서 머신러닝과 딥러닝의 핵심 문제는 "의미 있게? 데이터를 변환하는 것이다. 기대 출력과 비슷하도록 데이터의 유용한 표현(representation)을 학습하는 것이다.

표현이란 데이터를 바라보는 다른 방법이다. 예를들어 컬러이미지는 RGB포맷, HSV 포맷 두가지 다른 표현으로 볼수있다. 어떤 표현으로는 해결하기 어려운 문제가 다른표현으로 바라보면 쉬울수있다. 머신러닝 모델은 데이터에서 적절한 표현을 찾는게 전부다.

<img width="1280" height="472" alt="image" src="https://github.com/user-attachments/assets/431d42a4-0525-4d5e-9357-9fed13ad7597" />

위와같은 좌표(x,y) 데이터에서, 빨간색인지 흰색인지 출력하는 알고리즘을 어떻게 만들까? 직접 좌표 변환을 해주고 즉 새로운 표현으로 바꿔주고 x>0이면 빨강, x<0이면 흰색 이라는 규칙을 도입하면 색깔분류 문제를 해결할수있다.

이것보다 복잡한, 수기로 적은 6과 8의 차이점과 1과7의 차이점을 설명하는 규칙으로 숫자 분류 문제가 있다면 위처럼(이미지를 다른 표현으로 변환하고 직접 규칙을 만들기) 해결할수있을까? 어느정도는 가능하다. '닫힌 동심원의 수'와 같이 숫자 표현 기반으로 규칙을 만들거나 수직/수평 픽섹의 히스토그램으로 손글씨 숫자 분류 문제를 해결할수 있을것이다.

하지만 이렇게 만든 규칙기반 시스템은 망가지기쉽고 유지보수가 어렵다. 신중하게 생각해서 규칙을 만들어도 새로운 손글씨숫자 데이터가 나타날때마다 새로운 데이터변환이나 새로운 규칙을 추가해야 할것이다.

이게 어렵다면 이를 자동화할수있지 않을까? 자동으로 여러가지 데이터표현을 생성하고 각 데이터표현에 대한 규칙 중에 올바르게 분류한 숫자 비율을 피드백받아서 좋은 표현-규칙을 체계적으로 찾는건 어떨까?

이렇게 하면 머신러닝을 하는것이다. 머신러닝의 학습은 유용한 데이터표현을 만드는 데이터 변환을, 피드백신호를 바탕으로 자동으로 탐색하는 과정이다. (유용한 표현이라함은 간단한 규칙으로 문제를 해결할수있는 것이다)
