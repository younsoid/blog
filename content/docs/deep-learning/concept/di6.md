# 가중치 업데이트, 도함수, 그래디언트

#2026-07-31

---

### 1. 가중치 업데이트


```plain text
output = relu(dot(W, input) + b)
```

신경망의 각 층이 하는 일이 위 변환인데, 각 층이 다르게 갖는 값은 텐서 W와 b이다. 이는 가중치이며 각각 커널과 편향이라고 한다. 가중치에는 훈련 데이터로 학습된 정보가 들어있다.

가중치 업데이트는 이렇게 이뤄진다. 처음에는 가중치 행렬이 난수로 채워진다. (random initialization) 훈련은 훈련 반복 루프에서 이루어진다. (training loop) 손실이 충분히 낮아질때까지 훈련샘플 x와 타깃 y_true의 배치를 추출하고, x로 모델을 돌려보고(정방향 패스 forward pass) 예측 y_pred를 구해서 모델의 손실을 계산, 이번 배치의 손실이 감소하도록 모델의 모든 가중치를 업데이트한다. 

마지막 가중치 업데이트에서 값을 어떻게 얼만큼 업데이트할지를 어떻게 정할까?

젤 간단한 생각으로는 가중치행렬의 원소를 하나 빼고 다 고정하고 하나만 바꾸는것이다. 0.3이었고 손실이 0.5였는데 0.35로 바꾸면 0.6이 되고 0.25로 바꾸면 0.4가 된다고 하자. 그러면 가중치를 -0.05로 바꾸면 손실을 줄일수있다.

그럼 이걸 모든 가중치 행렬의 원소에 반복 적용하면 될까? 가중치가 보통 수천~수백만개인데 원소마다 두번의 정방향 패스를 계산하는건 매우 비효율적이다.

그래서 경사하강법을 쓴다. 요지는 가중치를 바꿨을때 손실값이 바뀌는값을, 그래디언트라는 연산을 사용하면 예측이 가능하다. 그래서 이 연산을 사용해서 손실이 감소하는 방향으로 가중치를 한번에 하나씩이 아니라 한번에 전체 가중치를 동시에 이동시킬수 있다.

그래디언트를 사용했을때 예측이 가능한 이유는 가중치와 손실을 매핑하는 함수가 미분가능하기 때문이다. 모델에 사용하는 dot이나 +같은 함수는 입력을 연속적인 방식으로 변환한다 즉 y의 변경 방향을 알면 z의 변경방향을 추측할수있다. 이 함수들을 연결해서 만든 함수도 미분 가능하다. 그래서 한번에 전체 가중치를 동시에 이동시킬수 있는것이다.

### 2. 도함수

<img width="1280" height="654" alt="image" src="https://github.com/user-attachments/assets/c8729512-e96e-449d-9ce1-313de2affc56" />

함수(신경망의 층)는 x를 y로 변환, 즉 x를 y로 매핑한다. 모델에 사용하는 함수는 미분가능하다고 했다. 

미분가능한 함수 f(x) = y를 보면 이 함수는 연속적이므로 x를 작은 값 epsilon_x만큼 증가시키면 y도 epsilon_y만큼만 바뀔것이다. (연속성)

<img width="1280" height="811" alt="image" src="https://github.com/user-attachments/assets/42c54958-1454-4a89-b887-a98d383677f5" />

또 이 함수는 매끈하므로 epsilon_x가 충분히 작으면 어떤 포인트 p에서 기울기 a의 선형 함수로 f를 근사할수있다.

```plain text
f(x + epsilon_x) = y + a * epsilon_x
```

따라서 epsilon_y는 a*epsilon_x가 된다. (x가 p에 충분히 가까울때)

여기서 기울기(정확히는 기울기 a의 선형 함수)를 p에서 f의 도함수라고 한다. 이는 a가 음수일때 p에서 x만큼 양수로 조금 이동하면 f(x)는 감소한다는 뜻이다. 

모든 미분가능한 (직관적으로는 연속적이고 매끄러운, 수학적으로는 도함수를 유도할수있는) 함수 f(x)에 대해서 x를 a로 매핑하는 도함수 f'(x)가 존재한다. (x를 f의 국부적인 선형 근사인 그 지점의 기울기로 매핑하는 함수)

함수를 미분할수있다는 것이 f(x)의 값을 최소화하는 x를 찾는 최적화 작업에 유용하다. f(x)를 최소화하기 위해 epsilon_x만큼 x를 업데이트하고싶을때 f의 도함수를 알면 해결된다.

도함수는 x가 바뀜에 따라 f(x)가 어떻게 바뀔지 설명해준다. f(x)의 감소시키고 싶다면 x를 도함수의 방향과 반대로 조금 이동하면 된다.

### 3. 그래디언트

함수(신경망의 층)는 x를 y로 변환, 즉 x를 y로 매핑한다고 했고 모델에 사용하는 함수는 미분가능하다고 했다. 

예시함수 f(x)는 스칼라 x를 스칼라 y로 바꾸는 함수였다. 스칼라 튜플 (x, y)를 스칼라 y로 바꾸는 함수는 벡터 연산인데, 도함수 개념은 표현이 연속적이고 매끄러운 모든 함수에 다 적용할수있다. 텐서 함수의 도함수를 그래디언트라고 한다. 

스칼라 함수 f(x)에서 도함수는 곡선의 국부적인 기울기였다. 텐서 함수의 그레디언트는 함수가 표현한 다차원 표면의 곡률(curvature)이다. 

###

### 4. 예시

그래디언트 개념이 실제 머신러닝에선 어디서 어떻게 적용되는지를 보면, 먼저 머신 러닝 모델이 W를 사용해서 예측 y_pred를 계산하고 y_pred와 y_true 사이 차이를 계산한다.

```plain text
y_pred = dot(W,x)
loss_value = loss(y_pred, y_true)
```

다음으로 그래디언트를 사용해서 loss_value가 작아지게 W를 업데이트해줘야한다. 이는 x와 y_true가 있을때 W를 손실에 매핑하는 함수로 볼수있을것이다.

```plain text
loss_value = f(W)
```

점 W0에서 f의 도함수는 W와 같은 크기의 텐서일 것인데 grad(loss_value, W0)이다.

텐서 연산 grad(f(W), W)는 스칼라 함수 grad_ij(f(W), w_ij)의 조합으로 표현할수있다. 이 스칼라 함수는 W의 다른 모든 가중치가 일정하다고 가정하면 가중치 W[i,j]에 대한 loss_value = f(W)의 도함수를 반환한다. 이 grad_ij를 W[i,j]에 대한 f의 편도함수라고 한다.

하나의 가중치를 가진 f(x)의 도함수는 곡선 f의 기울기였다. grad(loss_value, W0)은 W0에서 loss_value=f(x)가 가장 가파르게 상승하는 방향과 그 기울기를 나타내는 텐서이다. 편도함수는 f의 특정 방향 기울기이다. 

f(x)에서는 도함수의 반대방향으로 x를 움직이면 f(x)를 감소시킬수있었다. 텐서 함수 f(W)에서는 그레디언트의 반대방향으로 W를 움직이면 loss_value=f(W)의 값을 줄일수있다.

예를들어 W1 = W0 - step*(grad(f(W0), W0)이다. f가 가장 가파르게 상승하는 방향의 반대 방향으로 움직이면 곡선의 낮은 위치로 이동하게 된다는 뜻이다.

step은 스케일링 비율인데 grad(loss_value, W0)은 W0에 아주 가까이 있을때 기울기를 근사한것이므로 W0에서 너무 크게 벗어나지 않기 위해 step이 필요하다.
