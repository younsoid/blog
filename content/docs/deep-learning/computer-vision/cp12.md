# 패딩과 스트라이드

#2026-10-11

---

```plain text
입력 (5, 5, d1)
  ↓
conv2d(d2, 3, padding="valid")
  ↓
출력 (3, 3, d2)
```

5x5 입력 특성맵에서 3x3 격자는 9개를 만들수있다. 따라서 출력 특성맵은 가로세로가 2개씩 줄어들어 3x3이 된다.

```plain text
입력 (5, 5, d1)
  ↓
conv2d(d2, 3, padding="same")
  ↓
출력 (5, 5, d2)
```

입력맵과 높이, 너비가 동일한 출력맵을 얻으려면 패딩을 사용하면 된다. 

```plain text
입력 (28, 28, 1)
  ↓
conv2d(d1, 3)
  ↓ (26, 26, d1)
max pooling(2)
  ↓
출력 (13, 13, d1)
```
```plain text
입력 (28, 28, 1)
  ↓
conv2d(d1, 3, strides=2, padding="same")
  ↓
출력 (14, 14, d1)
```

특성맵을 다운샘플링할때 max pooling을 쓸수도 있지만 stride를 사용해줄수도 있다. 위처럼 경계 문제가 없는 입력맵에서는 /2로 다운샘플링된다.

```plain text
입력 (27, 27, 1)
  ↓
conv2d(d1, 3, strides=2, padding="same")
  ↓
출력 (14, 14, d1)
```

입력맵 크기가 27x27였다면, 패딩을 써줄 경우 +1후 /2한 14x14 크기로, 패딩을 쓰지 않을경우 -1후 /2한 13x13 크기로 다운샘플링된다. 

분류 모델에서는 다운샘플링에 스트라이드보다 최대 풀링을 더 많이 쓴다. 스트라이드는 잔차 연결에서 잔차 쪽 1×1 합성곱의 크기를 맞추는 식으로 많이 쓴다.
