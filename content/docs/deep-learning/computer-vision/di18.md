# 배치 정규화

#2026-10-09

---

### 1. 정규화

정규화는 모델의 input을 균일하게 만들어서 모델이 새로운 데이터에 잘 일반화하게 돕는다. 

가장 일반적인 정규화는 (x-평균)을 표준편차로 나누어 분산을 1로 만드는 것이다. 즉 데이터가 정규분포(가우스 분포)를 따른다고 가정하고, 데이터의 분포를 원점에 맞추고 분산이 1이 되게 조정하는 것이다.

위 정규화는 모델에 데이터를 주입하기 전에 하는 정규화이다. 하지만 데이터 정규화는 네트워크 안에서 필요한데, Dense나 Conv2D 층에 들어가는 데이터의 평균이 이고 분산이 1이더라도 출력되는 데이터가 동일한 분포를 갖지 않을 수도 있기 때문이다.

### 2. 배치 정규화

배치 정규화는 훈련하는동안 실시간으로 바뀐 평균과 분산을 사용해서 실시간 정규화를 한다. 

추론에서는 대표성을 가질만큼 충분히 큰 배치 데이터를 얻을 수 없는데, 이때 훈련에서 본 배치 데이터에서 구한 평균과 분산의 지수 이동 평균을 사용한다.

배치 정규화는 수학적으로 내부 공변량 변화를 감소시키는 효과가 있다고 알려져는 있지만 구체적으로 배치 정규화가 왜 도움이 되는지, 궁극적인 이유는 모른다고 한다. 하지만 배치 정규화를 쓰면 확실히 잔차 연결과 같이 그레디언트의 전파가 더 잘 이루어지는게 관찰된다.

### 3. 배치 정규화 사용하기

```python
x = layers.Conv2D(32, 3, use_bias=False, activation="relu")(x) # 사실 옳지않음
x = layers.BatchNormalization()(x)
```

배치정규화는 Dense, Conv2D 등의 층이 나오고 다음에 사용한다. 

Dense 층과 Conv2D 층은 편향 벡터를 갖는게 기본이다. 실제로 Conv2D 층은 y = conv(x, kernel) + bias이고 Dense 층은 y = dot(x, kernel) + bias이다. 

편향 벡터 bias를 넣으면 이 층이 순수 선형 변환이 아니라 아핀 변환이 된다.

근데 정규화는 층 출력의 평균을 0으로 만들기 때문에 뭘 더해놓는게 의미가 없고 그래서 편향 벡터가 필요없다.

```python
x = layers.Conv2D(32, 3, use_bias=False)(x)
x = layers.BatchNormalization()(x)
x = layers.Activation("relu")(x)
```

그리고 일반적으로 변환->활성화->정규화 보다는 변환->정규화->활성화 하는게 올바른 사용법이라고 한다. 

왜냐하면 배치 정규화는 평균을 0으로 만드는데 relu 활성화함수는 0을 기준으로 값을 통과 및 삭제시키기 때문에 평균을 0으로 맞추고 나서 relu를 돌리면 relu의 활용도가 높아지기 때문이다.
