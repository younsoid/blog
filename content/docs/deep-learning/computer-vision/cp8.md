# 잔차 연결

#2026-10-09

---

### 1. 잔차 연결

컨브넷 아키텍처를 설계할 때 유용한 방법으로는 잔차 연결, 배치 정규화, 깊이별 분리 합성곱 등이 있다. 이 패턴들을 사용하는 방법을 익히면 매우 효율적인 이미지 모델을 만들 수 있다.

y = f4(f3(f2(f1(x))))라는 네트워크가 있을때, 역전파는 오차 신호가 f4에서 f1 방향으로 거슬러 가는 것이다. 

이때 각 함수에는 일정량의 잡음이 있고 함수 연결이 너무 깊으면 이 잡음이 그래디언트 정보를 넘어서서 역전파가 동작하지 않게 된다. 

그레디언트 소실을 해결하려면 해당 층의 입력을 출력에 더하면 된다. (잔차 연결) 그러면 이전 입력에 담긴 잡음 없는 정보가 유지된다. 

입력을 블록의 출력에 더하려면 출력과 입력 크기가 같아야 할것이다. 

블록에 필터 개수가 늘어난 합성곱 층이나 최대 풀링 층이 들어있는 경우에는 활성화 함수가 없는 1x1 Conv2D 층을 사용해서 잔차를 원하는 출력 크기로 선형적으로 투영할 수 있다. 

### 2. 잔차 연결 사용하기

```python
inputs = keras.Input(shape=(32, 32, 3))
x = layers.Conv2D(32, 3, activation="relu")(inputs)
residual = x
x = layers.Conv2D(64, 3, activation="relu", padding="same")(x)
residual = layers.Conv2D(64, 1)(residual)
x = layers.add([x, residual])
```

모델의 입력은 (32, 32, 3)이다. 잔차 블록의 입력은 첫번째 Conv2D층의 출력 크기인 (30, 30, 32)이다. (padding이 없어서 가로세로가 1개씩 깎임)

잔차 블록을 통과한 출력은 (30, 30, 64)이다. 잔차 블록의 입력은 (30, 30, 32)이므로 1x1 2D를 사용해서 (30, 30, 64)으로 투영한다 즉 채널 개수를 64로 만들어준다. 그리고 블록 출력과 잔차를 더해준다.

1x1 2D (1x1 합성곱)의 구체적인 기능은? 이미지가 30×30 칸이고 각 칸에 숫자 32개가 쌓여 있는걸로 보면, 1×1 합성곱은 칸 하나만 보고 그 칸에 쌓인 숫자 32개를 섞어서 새 숫자 64개를 만든다. 활성화 함수 없이 쓰기 때문에 숫자를 단순히 섞기만 하는 선형 투영이 된다.

```python
inputs = keras.Input(shape=(32, 32, 3))
x = layers.Conv2D(32, 3, activation="relu")(inputs)
residual = x
x = layers.Conv2D(64, 3, activation="relu", padding="same")(x)
x = layers.MaxPooling2D(2, padding="same")(x)
residual = layers.Conv2D(64, 1, strides=2)(residual)
x = layers.add([x, residual])
```

위처럼 블록 안에 max pooling이 있어서 크기가 절반이 되는 경우에는 잔차 쪽 1×1 합성곱에 strides=2를 넣어서 가로세로를 맞춘다.

### 3. max pooling

max pooling은 근데 왜 하는걸까?

MaxPooling2D(2)는 특징 맵의 각 2×2 칸들에 대해서 가장 큰값만 남긴다. 즉 한번에 가로 하나, 세로 하나 칸이 제거된다. 채널 수(z축)은 그대로이다. 

합성곱 필터의 출력값이 크다는 건 그 위치에서 필터가 찾는 패턴(가장자리, 모서리 등)이 강하게 나타났다는 뜻이므로 2×2 구역에서 최댓값만 남기면 "이 근처 어딘가에 그 패턴이 있었다"는 정보는 보존되고, 정확히 몇 번째 픽셀이었는지는 없어진다. 즉 (이미지의 해상도가 아니라) 특징의 해상도가 낮아진다.

이렇게 줄이면 계산량이 줄어들고, 다음 층이 더 넓은 영역을 보게 된다. 축소된 맵에서 3×3 필터 하나가 덮는 범위는 원래 이미지 기준으로 두 배 넓다. 앞쪽 층이 선이나 점 같은 작은 패턴을 찾으면, 풀링 뒤의 층은 그것들을 조합해 눈, 바퀴처럼 더 큰 패턴을 찾을 수 있게 된다. 

잔차 블록의 Conv2D층의 출력은 (30, 30, 64)이다. MaxPooling2D 층의 출력은 (15, 15, 64)이다. 

그리고 위의 Conv2D층은 stride 2인 1×1 합성곱인데, padding="same"을 해주면 입력이 가로세로 31이었을때 출력이 32가 된다. 그래서 MaxPooling2D 층에서 padding="same"을 해줘야 입력이 가로세로 31이었을때 15가 아니라 16이 나오고 1x1 2D를 사용해서 가로세로 32로 만들수가 있다.
