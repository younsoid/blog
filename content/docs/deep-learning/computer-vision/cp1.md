# 컴퓨터 비전 작업 3가지

#2026-10-06

---

컴퓨터 비전 모델이라고 하면 보통 이미지를 받아서 개/고양이 분류하는 모델을 생각한다.

이러한 이미지 분류 문제 외에도 2가지 종류의 문제가 더 있는데, 이미지 분할 문제와 객체 탐지 문제이다.

이미지 분할 문제는 이미지를 다른 영역으로 '나누'거나 '분할'한다. 줌에서 사람과 배경을 분리할때 이미지 분할 모델을 사용한다.

객체 탐지 문제는 이미지에 있는 관심 객체를 감싸는 바운딩 박스 사각형을 그린다. 

분류, 분할, 탐지 외에 이미지 유사도 평가, 키포인트 감지(이미지에서 관심 속성을 정확히 짚어내기: 얼굴에서 얼굴을 구별하는 특징을 뽑는 등), 3D 메시 추정 등이 있다. 

<gray>wsi에서 이미지 분할을 적용한다음에 기질 같은건 걷어내고 분석하면 성능이 올라갈지도 모르겠다. 키포인트 감지도 응용 가능해보인다.</gray>
