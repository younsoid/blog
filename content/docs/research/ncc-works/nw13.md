### 1. 작업 개요

기존 분석에서 분석 대상자 368명 중 FMI 데이터가 있는 27명에 대해서 데이터 추출 작업을 수행해줬다. 이번 분석에서는 CNV, Fusion, MSI, TMB 데이터가 있는 대상자에 대해서 데이터 추출 작업을 진행할 예정이다.

CNV, Fusion, MSI, TMB 데이터는 eCRF의 Data Tool 파일에 존재하는데, sheet 0에 MSI와 TMB, sheet 1에 CNV 정보, sheet 2에 Fusion 정보가 있다. 

```python
DATA_DIR = r"C:\Users\User\Documents\yshid\2607\data"

MSI_MAP  = {"1": "MSS", "2": "MSI-L", "3": "MSI-H", "4": ""}                       # 4=Other→빈칸
COYP_MAP = {"1": "Gain", "2": "Loss", "3": "Amplification", "4": "Deletion", "5": ""}  # 5=Other→빈칸

add_up = {s.strip().upper() for s in add_sid}
seq_ids = set(data_tool_01["SUBJ_ID"].dropna().astype(str).str.upper())
missing = sorted(add_up - seq_ids)
print(len(add_up), len(add_up & seq_ids), len(missing)) # 368 329 39
```

MSI 컬럼은 1이 MSS, 2가 MSI-L, 3이 MSI-H, 4가 Other이다. Copy Number Type은 1이 Gain, 2가 Loss, 3이 Amplification, 4가 Deletion, 5가 Other이다.

기존 분석 대상자 368명 중 NGS Report가 있는 대상자를 확인했을때 329명은 정보가 있고 39명은 존재하지 않았다. 이에 329명에 대해서 CNV, Fusion, MSI, TMB 데이터를 추출해줬다.

```python
seq = data_tool_01[data_tool_01["SUBJ_ID"].astype(str).str.upper().isin(add_up)].reset_index(drop=True)

msi_tmb = pd.DataFrame({
    "SUBJ_ID":        seq["SUBJ_ID"],
    "TUMR_PRIT_RATE": seq["TUMR_PRIT_RATE"].map(_num),
    "TMB_TOTL_CNT":   seq["TMB_TOTL_CNT"].map(_num),
    "MSI":            seq["MSI"].map(lambda v: MSI_MAP.get(_code(v), "")),
    "QC_PASS":        seq["QC_PASS_YN"].map(lambda v: _code(v) or ""), 
})
tmb = msi_tmb[["SUBJ_ID", "TMB_TOTL_CNT", "QC_PASS"]].copy()
print(len(msi_tmb), len(tmb), msi_tmb["SUBJ_ID"].nunique()) # 338, 338, 329
```

먼저 MSI와 TMB 정보를 sheet 0에서 가져왔다. 추출 결과 데이터 수는 MSI 338개, TMB 338개였고 대상자는 329명에 대해 모두 존재했다.

```python
cnv_src = data_tool_03[
```

```python
fus_src = data_tool_04[
```

마지막으로 Fusion 데이터를 sheet 3에서 가져왔다. 추출 결과 데이터 수는 112개였고 대상자 38명에 대해 존재했다.
