# Paper #2 Whole slide images reflect DNA methylation patterns of human tumors

#2026-10-05

---

### 1. Introduction

* DNA 메틸화 = 유전자 발현 조절 핵심 후성유전 기전
	- 과메틸화(hyper)·저메틸화(hypo) 모두 암에서 발현 교란
	- 이상 메틸화 = 가장 흔한 암 분자 변화, 바이오마커·드라이버로 주목
* TCGA: 10,000+ 샘플 메틸화 어레이 → 방대한 데이터
* 메틸화의 임상 적용 한계
	- 질환마다 바이오마커 성능 제각각, 검증 진행 중
	- 결과까지 수주 소요 → 치료 결정 지연
* 반면 WSI = 암 의심 시 거의 항상 확보, 조직 구조·세포 구성 정보 풍부
* 기존 WSI 계산병리 연구
	- C-Path(유방암): 생존 예측 최고 특징이 종양이 아닌 주변 기질에서 나옴
	- 교모세포종: 조직 이미지 + 유전체 → CNN 생존 예측
	- SPM(spatial pyramid matching): 핵 형태 통계로 다중 위치·스케일 맥락 특징 구성
* 목표: 메틸화 패턴이 WSI에 반영되는지, 고전 머신러닝으로 예측 가능한지
* 대상: 조직 기원이 전혀 다른 두 암 = 신경교종(glioma), 신세포암(RCC)

<grayblock>

- 이상 메틸화가 암 유발할수 있거나 예후 예측에 쓸수있다.
- 그렇지만 메틸화로 암을 진단하기에는 아직 명확한 마커가 발굴된바가 없다. 암 진단에는 보통 WSI를 쓴다.
  - WSI로 메틸레이션을 예측할수있을까?
- 기존 wsi 연구의 진행 사항은
  - 유방암 이미지(암 상피와 주변 기질)에서 특성을 추출해서 생존 분석했는데 생존을 가장 잘 예측이 특징은 암세포 자체가 아니라 그 옆의 기질이었다.
  - 조직 이미지와 유전체 바이오마커를 합쳐 합성곱 신경망(CNN)으로 생존을 예측할수가 있다. 즉 이미지, 유전체, 딥러닝 분석이 가능하다.
  - 이미지 스캐너와 환자 개인의 특성에 의한 배치를 없애기 위해서 공간 피라미드 매칭(SPM)을 도입할수가 있다.
- 메틸화 같은 분자 정보와 WSI의 조직 정보가 있을때
  - 두 정보 사이의 관계는? 통합해서 사용하려고 하는데 같은 것을 말하고 있다면 하나로 다른 하나를 대신할 수 있고, 전혀 다른 것을 말하고 있다면 둘을 합쳤을 때 시너지가 클 것.
  - 기존 연구는 이미지로 생존을 예측하거나 이미지와 유전체를 합쳐 생존을 예측했고 "이미지 자체가 메틸화를 얼마나 반영하는가"라는 질문은 다루지 않았다.
- 메틸화 패턴이 WSI에 반영되는지, 반영된다면 어떻게 반영되는지를 확인한다.
  - "핵 면적의 분포", "핵 장축의 사분위 범위"처럼 사람이 이해할 수 있는 형태 특징을 입력으로 한 머신러닝을 사용해서 해석가능성도 본다.

cf) 암의 기작 관련 pathway와 메틸레이션의 작동영향을 많이 받는 pathway를 봣을때 교집합은? 그리고 그 pathway가 많이 관여하는 암종을 고르면?

- 연구 기작은 신경교종과 RCC 샘플에서 WSI로부터 뽑은 형태 특징으로 메틸화 상태를 예측.
- 비슷한 메틸화 패턴을 가진 유전자들을 묶어 군집 단위로 예측하면 성능이 크게 좋아지는걸 확인한다. 그리고 잘 예측되는 유전자들이 어떤 생물학적 경로에 속하는지 경로 분석으로 본다.

</grayblock>

### 2. Background

2.1 MethylMix와 DM 값
* 저자 그룹이 개발한 beta mixture model 기반 메틸화 드라이버 유전자 탐지 도구
* 정상 vs 암 메틸화 + 유전자 발현 통합
	- 조건: 정상 대비 차등 메틸화 + 발현까지 예측하는 유전자
* 출력 = DM(Differential Methylation) 값 = 비정상 상태 - 정상 상태
	- 양수 = 과메틸화, 음수 = 저메틸화, 0 = 정상
* 활용 사례
	- 두경부암: DM 기반 5개 아형 → HPV·흡연 원인군과 더 잘 맞음
	- 편평세포암: NSD1 비활성 저메틸화 아형
	- 단백체 데이터로 후보 추가 압축 가능

<grayblock>

- 전사적으로 예측력이 있는(transcriptionally predictive) 유전자를 MethylMix로 식별 가능하다.
  - 메틸화가 되었다고 해서 발현이 무조건 바뀌는게 아닌데, 실제로 발현량을 바꾸는 메틸레이션을 식별하는 툴이 MethylMix이다. 
  - beta mixture model을 메틸레이션 데이터에 적용해서 DM 값(Differential Methylation value)을 낸다. 양수면 정상 대비 과메틸화다.
  - DM 값으로 기존 유전자 발현 기반 subtype과 다른 subtype을 식별한 연구도 있다.

</grayblock>

2.2 형태계측(morphometric) 특징
* 세포 단위 측정값: 핵 면적·장단축·곡률·질감·강도, 세포질 강도·기울기 등
* 맥락(contextual) 특징: 세포 구성·이질성 요약
* 환자 단위로 요약 통계화: mean, median, SD, skewness, kurtosis, IQR

<grayblock>

- 크기, 모양 특징
  - 종횡비(aspect ratio): 핵이 동그란지 길쭉한지
  - 곡률(curvature): 윤곽선이 얼마나 급하게 휘는지 / 굽힘 에너지(bending energy): 윤곽선 전체가 얼마나 구불구불한지 / 볼록성 편차(deviation from convexity)는 핵 가장자리가 움푹 들어간 곳이 있는지. (정상 세포의 핵은 매끈하고 둥근데 암세포의 핵은 울퉁불퉁하고 찌그러지는 경우가 많음)
- 색과 무늬
  - 핵 안의 염색 강도(intensity): DNA가 얼마나 빽빽하게 뭉쳐 있는지
  - 기울기(gradient): 밝기가 얼마나 급격하게 바뀌는지 즉 경계나 내부 구조가 얼마나 또렷한지
  - 질감 특징(texture feature 0~11): 핵 안의 명암이 고르게 퍼져 있는지, 알갱이처럼 얼룩덜룩한지 (병리의사가 "염색질이 거칠다"거나 "미세 과립상이다"라고 말하는 것을 수치화)
    - 핵 안의 명암 무늬는 염색질이 어떻게 접혀 있느냐를 반영하는데, 메틸화가 염색질 구조와 엮여 있다는게 논문에서 나온다고함.
- 등등 35개 측정값 + 6가지 통계 + 맥락 특징 8개 -> 환자당 약 200개 feature
- 환자 수: 신경교종 342명, RCC 326명

</grayblock>

2.3 대상 암
* 신경교종
	- 신경교 줄기·전구세포 유래, 원발성 뇌종양 사망 대부분
	- 조직형: 성상세포·핍지교세포·뇌실막세포종
	- WHO II–III = LGG, IV = GBM (괴사·미세혈관 증식으로 구분)
	- WHO 2016: 조직 + 분자 통합 분류 강조
* RCC
	- 신세뇨관 상피 유래, 신장암 90% 이상, 10개 이상 아형
	- 투명세포·유두상·혐색소·집합관·미분류, 투명세포형(ccRCC) 최다

### 3. Method

3.1 데이터
* 메틸화: Illumina 450K, NCI GDC
	- TCGA glioma 932명, ccRCC 519명
* WSI: GDC 포털
* 메틸화 + 형태 특징 둘 다 있는 환자만 분석
	- glioma 342명, RCC 326명

3.2 메틸화 상태 정의 (MethylMix)
* 드라이버 유전자 선별 → 환자별 DM 값 행렬
* 3상태: 과메틸화(+) / 저메틸화(-) / 정상(0)
* 필터링
	- 한 상태가 환자 90% 초과 → 제외 (클래스 불균형 방지)
	- 상태가 1개뿐이거나 3개인 유전자 → 제외
	- 정확히 2상태 유전자만 → 이진 분류로 통일

3.3 유전자 군집화
* 비슷한 메틸화 패턴 유전자끼리 계층적 군집화
* 군집 수: 히트맵 육안 확인 + silhouette score → 5개 선택
* 군집 DM 값 = 군집 내 유전자 DM 평균
* Gaussian mixture model로 최적 임계값 → high/low 이진화
[보충 그림 1]

3.4 이미지 특징 추출
* ref.16(Chang et al., morphometric context) 방법으로 추출된 특징 사용
* 환자당 세포 형태 특징 35개 + 맥락 특징 8개
* 6개 요약 통계로 확장 (mean, median, SD, skewness, kurtosis, IQR)
[보충 표 1]

3.5 다변량 모델링
* 입력 = 형태 특징, 정답 = 유전자(또는 군집)별 이진 메틸화 상태
* 유전자·군집마다 개별 분류기 = multitask + multivariate 분류
* 30회 무작위 분할: 학습 75% / 테스트 25%
* 학습셋 내 5-fold CV로 하이퍼파라미터·정규화 강도 선택
* 특징 많고 샘플 적음 → 정규화로 과적합 억제
* 모델 6종 (scikit-learn)
	- 로지스틱 회귀(lasso), 랜덤포레스트(트리 수)
	- SVM(linear/rbf 커널, C), AdaBoost(학습률, 추정기 수)
	- Naive Bayes, 2층 완전연결 신경망(학습률)
[그림 1] 전체 파이프라인 (WSI → 특징 → 모델 ← DM 값 ← MethylMix)

3.6 평가
* 지표: accuracy, precision, recall, F1, ROC·AUC, PR curve
* 과제별로 30회 결과 평균
* 로지스틱 회귀 계수로 특징 중요도 순위화
* 비교: 임상 특징만(나이·성별·병기) vs 임상 + 형태 특징

### 4. Results

4.1 신경교종 유전자 단위 예측
* MethylMix → 927개 드라이버 유전자
* 6모델 중 Naive Bayes만 평균 AUC < 0.7 → 이후 제외
* 나머지 5모델 평균: AUC 0.74, F1 0.64
* 모든 모델에서 AUC·F1 > 0.8 유전자 8개
	- CDK4, COL5A1, CPA4, CSTB, MMP7, MYCBP, PPIC, TMEM59
* 대표 유전자
	- CDK4: G1→S 세포주기 진행, 신경교종에서 자주 변이
	- MYCBP: C-MYC 결합 단백질, S기에 핵 이동, 위암 침윤·이동 촉진
	- CDK4·MYCBP: LR·SVM·NN에서 AUC > 0.94, F1 > 0.84
	- TMEM59(DCF1): 신경줄기세포 분화, 신경교종 세포주 세포사멸, 전 모델 AUC > 0.91
	- MMP7: ECM 분해로 침윤, SVM AUC 0.92 / F1 0.85
[그림 2] (a 모델별 5개 지표 violin plot, b CDK4·MYCBP ROC·PR)

4.2 신경교종 군집 단위 예측
* 군집 단위로 묶자 성능 크게 향상
* cluster 2 제외 모든 군집 AUC·F1 > 0.8
[그림 3] (a 계층적 군집 히트맵 hc3~hc7, b hc5 군집별 ROC·PR·violin)

4.3 RCC 예측
* 326명, MethylMix → 366개 유전자
* 전반적으로 신경교종보다 낮음: 5모델 평균 AUC 0.58
* 모든 모델 AUC·F1 > 0.6 유전자 5개
	- DAK, ITPRIP, LCP1, TM4SF19, TMEM200A
* LCP1: L-plastin, 비조혈 기원 악성세포에서 발현, 조기 신장암 바이오마커 3종 중 하나
	- LR·SVM에서 AUC > 0.7, F1 > 0.65
* 군집화(k=5) 시 향상: cluster 2·3·4 평균 AUC > 0.66, F1 > 0.54
[그림 4] (a violin plot, b TM4SF19·LCP1 ROC·PR)
[그림 5] (a RCC 군집 히트맵, b hc5 군집별 성능)

4.4 유전자셋 농축 분석 (Hallmark, MSigDB)
* 신경교종
	- GoodPredSet: ≥4모델에서 AUC·F1 > 0.7, 321개
	- BadPredSet: 전 모델 AUC·F1 < 0.6, 45개
	- Good에만 농축: apoptosis, hypoxia, IFN-γ·IFN-α response, inflammatory response, EMT, KRAS signaling up, coagulation 등
	- 저산소 → 침윤 촉진, 교모세포종 세포 형태 변화
* RCC
	- Good = cluster 2·3·4 유전자, Bad = 나머지 2개 군집
	- Good에만 농축: angiogenesis, estrogen response late
	- 혈관신생 → 혈관 밀도·패턴 등 형태 변화 유발
[표 1]

4.5 특징 중요도
* 임상 특징만 vs 임상 + 형태: 형태 추가 시 두 암 모두 크게 향상
[그림 6]
* LR 상위 25% 특징 중 두 암 공통 4개
	- nucleus max curvature s1 IQR
	- nucleus major axis IQR
	- nucleus minor axis IQR
	- nucleus area robust skewness
	- 대부분 핵 크기·모양의 환자 내 분포(퍼짐·비대칭) 지표
[그림 7] (a glioma, b RCC)

### 5. Discussion

* 요약: WSI 형태 특징으로 유전자·군집 메틸화 상태 예측 가능
* MethylMix 이산화 표현 = 원시 메틸화 잡음 제거 효과
	- 출력 단위는 유전자뿐 아니라 개별 CpG·CpG 군집도 가능
* RCC 성능 낮은 이유 (저자 해석)
	- 두 코호트의 종양 이질성 수준 차이
	- 조직 기원 차이 → 메틸화 패턴 자체가 다름
	- 드라이버 유전자 927 vs 366 → 신경교종이 후성유전적으로 더 이질적
	- 신경교종은 메틸화가 세포 형태에 더 크게 영향
* 의의: 메틸화 검사는 비싸고 느리고 조직 평균값만 제공 → 접근성 높은 WSI와 연결
* 관련 연구
	- 20개 암종 생존 예측 다중모달 신경망 (임상·mRNA·miRNA·WSI)
	- 폐암 WSI 딥러닝: LUAD/LUSC/정상 분류 + 6개 변이(STK11, EGFR, FAT1, SETBP1, KRAS, TP53) 예측
	- MSI 예측: CT 라디오믹스(대장암), 조직 이미지 딥러닝(위장관암)
* 잘 예측된 유전자
	- 알려진 암 관련: CDK4, MMP7, MYCBP, TMEM59, LCP1
	- 연구 부족 → 후속 연구 가치: COL5A1, CPA4, CSTB, PPIC, DAK, ITPRIP, TM4SF19, TMEM200A
* 메틸화가 형태에 반영되는 가설 기전
	- 메틸화 ↔ 염색질 공간 구조 반영
