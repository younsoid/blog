# 3차 연구계획 자료

#2026-10-27

---

연구가 정리가 안돼서 .. 좀 깔끔하게 다시 바꿔봤다.

그리고 이참에 코드도 좀 깔끔하게 짜라고 했다. 너무 쓸데없는 예외처리와 출력들이 많아서 깔끔하게 짜라고 했다. 

그래야 돌리면서도 이해가 되고 바로바로 이상한점을 수정할수있을듯하다.

###

## 0. 연구 방향

지금까지(v3, 노트북 06~19d)의 질문은 "H&E 이미지로 분자 라벨(메틸화 LF, 그 순도 잔차 등)을 예측할 수 있는가"였다. 라벨을 바꾸고(LF → lf_resid → ic_resid_tref), 모델을 바꾸고(선형 → ABMIL), 기관 효과를 보정해도 예측은 ρ ≈ 0.2 근처에서 움직이지 않았다. 가장 큰 원인은 **진단용 FFPE 슬라이드(DX)와 분자 분석에 쓴 냉동 조직이 같은 종양의 다른 부위**라는 점이다. TCGA는 냉동 조직의 위·아래 단면으로 TS·BS 슬라이드를 만들고 가운데에서 DNA·RNA를 뽑지만, DX 슬라이드와 분자 조직의 위치 관계는 알 수 없다 (Cooper et al., J Pathol 2018).

새 계획은 질문의 주어를 바꾼다. **"H&E에서 직접 재는 면역미세환경 feature 하나"를 정의하고, 분자 데이터는 정답이 아니라 그 feature의 생물학적 해석과 검증에 쓴다.** 그리고 공개 병리 파운데이션 모델(UNI, CONCH, Virchow, EXAONEPath 등) 위에 MIL 모델을 학습해 attention heatmap을 얻고, 그 heatmap을 생물정보학적으로 해석한다.

## 1. 핵심 설계 원칙: 주장을 세 층위로 나눈다

| 층위 | 주장의 형태 | 쓰는 데이터 | 조직 불일치의 영향 |
|---|---|---|---|
| ① 영상 단독 | "H&E feature X가 예후와 관련된다" | DX 슬라이드 + 생존 | 없음 |
| ② 환자 수준 생물학 | "X가 높은 환자는 이런 분자 프로그램이 활성화되어 있다" | DX feature + TCGA 다중오믹스 | 있음 → 상관이 희석됨. 방향·일관성으로 해석하고, TS·BS 병리 판독값(기본)·TS 이미지(선택)로 희석 정도를 정량화 |
| ③ 공간 생물학 | "attention이 높은 곳에 이런 유전자·세포가 있다" | **같은 절편**에 H&E와 공간전사체가 있는 데이터 | 없음 |

층위 ③이 이 계획의 핵심 보완점이다. attention heatmap의 생물학적 정체는 TCGA bulk로 검증할 수 없지만, 같은 절편 데이터(10x Visium/Visium HD/Xenium 폐암, HEST-1k 폐)로는 위치 대 위치로 직접 검증할 수 있다.

## 2. 연구 질문과 가설

| 번호 | 질문 | 가설 |
|---|---|---|
| Q1 | H&E에서 정량한 TLS 부담 지수는 병기·임상 변수와 독립적으로 예후와 관련되는가 | 높을수록 OS가 좋다 (탐색 단계: 림프구 응집 HR 0.76) |
| Q2 | 이 지수는 단순한 림프구 양(TIL)을 넘어서는 정보인가 | TIL(Saltz TIL RF, 전 슬라이드)을 보정해도 남는다 |
| Q3 | 환자 수준에서 어떤 분자 프로그램과 연결되는가 | B세포·형질세포·CXCL13·TLS 케모카인 축이 메틸화–RNA–단백질 세 층에서 일관되게 높다 |
| Q4 | 파운데이션 모델 + MIL은 이 지수를 학습할 때 실제로 TLS를 보는가 | attention 상위 영역이 TLS 검출 다각형과 겹친다 |
| Q5 | attention이 높은 위치의 분자적 정체는 무엇인가 | 같은 절편 공간전사체에서 MS4A1, CR2, CXCL13, CCL19/21, LAMP3 등 TLS 유전자가 높다 |
| Q6 | 결과는 외부 코호트와 다른 정의에서도 재현되는가 | CPTAC에서 같은 방향, TLS 정의(개수·면적·배중심)를 바꿔도 유지 |

ICI 치료 정보는 TCGA에 없으므로, 결론은 "예후와 면역 생물학"까지로 한정한다. ICI 반응 예측은 후속 연구 범위다 (서베이 7.4절: 예후 인자와 예측 인자의 구분).

## 4. 2단계 — 원고 방식의 기본 다중오믹스 분석 (2~3주)

첨부 원고의 분석 골격을 폐암 면역미세환경 축으로 옮긴다. LUAD와 LUSC는 분리해 분석한다.

| 원고 절 | 폐암 적용 |
|---|---|
| 2.3 MAF 기반 TMB 대리값 | GDC masked MAF로 비동의 변이 수, 코호트 내 3분위. STK11·KEAP1·EGFR·KRAS 상태 |
| 2.4 TSS200 중심 메틸화 | 면역 유전자 프로모터 메틸화 (CD8A, GZMB, PRF1, CXCL13, MS4A1, CD19, CR2, CCL19, CCL21, LAMP3 등). β는 해석용, z는 시각화용. 참고 지표로 메틸화 기반 TIL 점수(MeTIL) |
| 2.5 TPM, ESTIMATE, CIBERSORT absolute | 동일 + MCP-counter. 면역 요약 점수(세포독성, 관문·탈진, B세포, T세포, NK, 대식세포, Treg) |
| 2.6 단백질 | RPPA (TCGA), TMT 단백체 (CPTAC) |
| 2.9 메틸화–RNA–단백질 상관, 경로 묶음 | 면역 유전자군에서 세 층 상관 분포와 역상관 비율 |
| 2.13 Cox, KM, LASSO | 병기·나이·흡연 보정, OS와 PFI 병행, 연속형과 3분위 |

원고의 "면역 프로그램이 메틸화–RNA 역상관과 RNA–단백질 전파가 가장 강했다"는 결과가 폐암에서도 재현되는지 본다. 재현되면 이후 TLS feature의 분자적 해석에 쓸 면역 프로그램 점수를 세 층에서 일관되게 정의할 수 있다.

| 번호 | 재현 대상 | 기대 결과 | 통과 기준 |
|---|---|---|---|

| R2 | Bagaev 미세환경 아형 (Cancer Cell 2021, MFP 코드) | IE/F·IE·F·D 네 아형, 면역 친화 아형의 예후 우위 | 네 아형 재현, 생존 방향 일치 |
| R3 | PRECOG (Gentles, Nat Med 2015) | 형질세포 시그니처 좋은 예후, 호중구 나쁜 예후 (폐선암 포함) | CIBERSORT 형질세포 HR < 1, 호중구 HR > 1 |
| R4 | STK11·KEAP1 면역 냉각 (Skoulidis 2018; Gillette, Cell 2020) | STK11 변이 LUAD의 면역 점수 저하 | TCGA·CPTAC 모두 같은 방향 |

| R7 | Saltz TIL map (Cell Rep 2018) | TIL 밀도·공간 구조가 면역·분자 아형과 연관 | TIL RF와 아형·생존 관계 (19d: OS HR 0.81) |

R2~R6이 새로 할 일이다. 재현이 안 되면 데이터 처리 과정을 먼저 점검한다.

## 6. 4단계 — feature 아이디에이션과 선정 (1~2주)

서베이의 H&E 가시성 스펙트럼(3.4절)과 대리 지표 사슬(3.1.3절)을 선정 기준으로 쓴다.

| 기준 | 이유 |
|---|---|
| H&E 가시성 "높음~중간" | DX에서 분자 정답 없이 직접 잴 수 있어야 층위 ①이 성립 |
| 문헌상 예후·ICI 근거 | 서베이 표 3·4에서 임상 검증까지 간 항목 |
| 분자 대응물 존재 | 층위 ②·③의 해석 가능 |
| TIL 양의 재발견이 아님 | 서베이 5.5절 "조건부 부가 가치" |
| 우리 데이터의 사전 신호 | 탐색 결과와 일치 |

| 후보 | 가시성 | 문헌 | 분자 대응물 | 우리 데이터 신호 | 판단 |
|---|---|---|---|---|---|
| **A. TLS·림프구 응집 부담** | 높음~중간 | 서베이 [26, 88, 89], R5·R6 | B세포, CXCL13, CCL19/21, 형질세포 | 응집 HR 0.76 (25가지 정의에 강건), TIL RF와 공유 | **1순위** |
| B. 면역 표현형 (침윤 지수) | 높음 | 서베이 [23] | 세포용해 활성 | C4만 구별, 예후 무관 | 보조 |
| C. 면역 냉점 수 | 높음 | 서베이 [25] | — | 29구역으로 측정 불가 | 전 슬라이드 분석 후 재평가 |
| D. 형질세포 풍부 침윤 | 중간 | 서베이 [55], R3 | IGHG, MZB1, JCHAIN | 미측정 | A의 성숙도 하위 지표로 편입 |
| E. 조직 호중구/림프구 비 | 높음 | R3, CPTAC | 호중구 탈과립 | 미측정 | 탐색 |

**결정: feature는 "TLS 부담 지수" 하나.** 정의는 영상에서, 해석은 분자에서 한다.

탐색 단계(19b~19d)에서 확인한 두 한계를 반드시 고친다. ① 29개 구역(조직의 약 4%)만 본 것 → **전 슬라이드**에서 잰다. ② HoVer-Net이 작고 빽빽한 종양 핵을 림프구로 오분류한 것 → **전용 TLS 검출기**를 쓴다. 기준 검출기는 HookNet-TLS (van Rijthoven, Commun Med 2024; 공개, Grand Challenge). TCGA KIRC·BLCA·LUSC 1,019장의 수작업 주석으로 학습했으므로 LUSC에서는 학습 슬라이드를 빼고 평가하고, LUAD는 외부 적용으로 다룬다. 입력은 0.5 µm·2.0 µm 해상도를 담은 다중 해상도 TIFF와 조직 배경 분할이다.

지표 후보는 TLS 개수/조직 mm², TLS 면적 비율, 배중심(GC) 유무 세 가지다. **분석 전에 주 지표 하나를 사전 등록**하고 나머지는 민감도 분석으로 둔다 (서베이 4.2.2절: TLS 정의가 연구마다 다르다는 문제).

## 7. 5단계 — feature → 파운데이션 모델 → attention → 생물정보학 (4~6주)

| 단계 | 내용 | 산출물 |
|---|---|---|
| 5-1 학습 | 타일 임베딩에 ABMIL·CLAM을 붙여 TLS 부담 지수를 예측. 주 모델은 이미 추출한 EXAONEPath 1.0, 비교용으로 UNI(또는 UNI2)·CONCH·Virchow 중 1~2개. 라벨이 같은 슬라이드의 영상 지표이므로 조직 불일치 없음 | 기관 단위 5-fold 성능, 모델 간 비교 |
| 5-2 attention 점검 | attention 상위 타일과 HookNet-TLS 다각형의 겹침(정밀도·재현율), 겹치지 않는 고-attention 영역의 정체 | "모델이 TLS를 보는가"의 정량 답 |
| 5-3 영역 표현형 | attention 상위 영역을 HookNet-TLS의 TLS·GC 구분과 EXAONEPath 임베딩 군집으로 분류 (성숙 TLS+GC, 종양 인접 응집, 기관지 주변 BALT 유사 구조 등) | 패턴별 환자 점수 |
| 5-4 층위 ② | feature·패턴별 환자군의 RNA 차등발현·GSEA, CIBERSORT, 프로모터 메틸화, RPPA, 세 층 상관 | B세포·형질세포·CXCL13 축의 다층 일관성 |
| 5-5 층위 ③ | 학습한 모델을 10x 폐암 Visium/HD/Xenium 절편 H&E에 적용 → spot별 attention과 같은 spot 유전자 발현, CD20 IF와의 공간 일치 | attention의 공간적 분자 정체 |
| 5-6 단일세포 | 5-4·5-5의 유전자를 폐암 단일세포 아틀라스에서 세포 유형별로 확인 | 원고 2.7절의 폐암판 |

5-1에서 기관 단위 분할은 반드시 유지한다 (06 QC: 임베딩 주성분 변동의 68%를 기관이 설명). 5-5는 표본이 몇 개 수준이라 통계 검정보다 기전 확인으로 위치를 정한다.

## 8. 6단계 — 검증과 견고성 (3~4주, 5단계와 병행)

| 검증 | 방법 | 서베이 연결 |
|---|---|---|
