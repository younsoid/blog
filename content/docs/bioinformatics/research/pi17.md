# 2차 연구 계획: 정리된것

#2026-10-13

---

아직 저번 결과 돌린것도 덜봤는데 논문 읽다가 어쩌다보니 2차 계획을 뽑게되었다..

###

요약
- 실험 1·3: WSI → 메틸화 면역 라벨 6종(LF 연속값·이진, 군집, 디컨볼루션 비율)
- 실험 2: WSI → 순도 / WSI → LF(순도·다형성·흡연 통제)
- 실험 4: WSI → 핵 종류·형태(HoVer-Net) / 세포 특징 ↔ LF, SF, Prolif
- 실험 5: 임상 + 메틸화 LF + 공간 특징 + 다형성 → 생존
- 실험 6: WSI + 메틸화(PCA·디컨볼루션) → RNA 유래 타깃(ESTIMATE, 생존) / WSI + RNA → 메틸화 유래 타깃

###

0. 이식 전 정비
* 분할
	- 06·07a·08b: GroupKFold(환자 단위)로 교체
	- site-aware split 추가: 바코드 2번째 필드(TSS) 기준, 같은 기관은 한쪽에만
	- 환자당 여러 슬라이드: 슬라이드 임베딩 평균 또는 환자 단위 MIL로 통일
* 배율: 1.0도 MPP 기준 타일링 (0.5 µm/px 기준 256px), MPP 없는 슬라이드는 목록으로 따로 관리
	- [추가] 핵 크기 특징(실험 4b)은 µm 단위로 환산해서 저장 → 배율이 섞이면 다형성 값이 무의미해짐
* 암종 분리: LUAD·LUSC 각각 분석, 합칠 때는 조직형을 공변량으로
* 순환 제거: 라벨 정의에 쓴 변수는 입력에서 제외 (실험 6)

실험 1. 라벨 정의 비교
* 질문: 라벨 정의에 따라 예측 가능성과 생물학적 의미가 어떻게 달라지나
* 라벨 후보 (WSI 특징·모델 고정)
	- (a) LF 연속값 회귀
	- (b) LF 중앙값 이진화
	- (c) LF 상·하위 삼분위 이진화
	- (d) 분산 상위 probe KMeans (현재 08a 방식)
	- (e) 면역세포 특이 CpG만으로 만든 클러스터
	- (f) reference 기반 디컨볼루션 면역세포 비율 (EpiDISH/MethylCIBERSORT, 종양·기질 reference 포함)
* 평가: AUROC·Pearson r + 외부 지표 일치도 (RNA ESTIMATE 면역 점수, 생존)
* 해석 기준: 잘 맞혀지는 라벨 ≠ 의미 있는 라벨인지 확인

실험 2. 교란 변수 통제
* 질문: 면역을 맞힌 것인가, 순도·등급·흡연을 경유한 것인가
* 변수: ABSOLUTE 순도, pack-years, 병기, 조직형
	- [추가] 등급 대리 지표: 실험 4b의 종양세포 다형성(top-k) → TCGA에 등급 정보가 없으므로 이것으로 대체
* 분석
	- WSI로 순도 자체를 얼마나 맞히나
	- LF 예측의 편상관 (순도 통제, 다형성 통제 각각)
	- 순도 층별 하위 집단에서 예측력 유지 여부
	- 08a 클러스터 × 조직형·순도·흡연 교차표

실험 3. 집계·학습 방식 비교
* EXAONEPath 1.0 타일 특징 고정
	- (a) mean_std + 선형 모델 (nested CV로 α·C 튜닝)
	- (b) ABMIL 분류
	- (c) ABMIL 회귀 (MSE)
	- (d) ABMIL 회귀 (Balanced MSE)
	- (e) PANTHER 형태 원형 요약 + 선형 모델
	- [추가] (f) top-k pooling: 가장 거친 영역을 보는 병리 원칙과 대응
* EXAONEPath 2.5: slide embedding + 선형 모델, 같은 환자 집합
	- 2.5 사전학습에 TCGA 폐암 포함 여부 확인 → 포함 시 실험 7 외부 검증 필수
* [추가] 가설: 비율형 타깃(LF·SF)은 mean·attention 계열, 등급형 타깃(Prolif·다형성)은 top-k 계열이 유리

실험 4. 해석 가능한 세포 기반 기준선 [확장]
* 공통: PanNuke HoVer-Net으로 핵 분할·분류 (종양성/염증/결합조직/괴사/비종양 상피)
* 4a. 세포 구성
	- 슬라이드별 염증세포·결합조직·종양 비율 → LF·SF와 직접 비교 + 선형 회귀
	- EXAONEPath 모델과 성능 비교
	- 불일치 환자 슬라이드 직접 검토 (폐포 대식세포, 반응성 상피, 탄분 색소)
* 4b. 핵 다형성 변형 [추가]
	- 핵별 측정: 면적, 장·단축, 이심률, solidity, 둘레, 염색 강도, 질감 (µm 단위)
	- 영역 단위: 약 0.5–1 mm² 창 또는 동네 단위, 종양 핵 30개 이상인 영역만 사용
	- 영역별 변이 지표: 표준편차, IQR, 변동계수(CV)
	- 슬라이드 요약 4종
		- ① 전체 핵 혼합, 슬라이드 전체 흩어짐 (Zheng·SlideGraph+ 방식)
		- ② 종양 핵만, 슬라이드 전체 흩어짐
		- ③ 종양 핵만, 영역 평균
		- ④ 종양 핵만, 상위 영역 (top-1 / 상위 5% / 상위 10%) → "가장 덜 분화된 영역" 대응
* 4b 가설
	- H1: ①은 LF와 상관이 크지만, 염증세포 비율을 통제하면 대부분 사라짐 (세포 섞임 효과)
	- H2: ④는 면역보다 Prolif·고등급 패턴과 더 강하게 연관 (진짜 종양 다형성)
	- H3: ④는 실험 2에서 통제해야 할 교란 변수 역할
* 4b 분석
	- ①–④ 각각과 LF·SF·Prolif·면역 라벨의 상관
	- 염증세포 비율 통제 편상관
	- ①과 염증세포 비율의 상관 (섞임 효과 직접 확인)
	- 딥러닝 특징에 ④를 추가했을 때 예측력 변화
* 4b 검증
	- TCGA에 병리 등급 없음 → Prolif 점수, 유사분열상 밀도와의 상관으로 간접 검증
	- 소규모(약 30장) 병리의사 검토: ④가 고른 상위 영역이 실제로 가장 거친 영역인지
* 4b 주의
	- 폐의 반응성 폐포 상피가 종양성으로 오분류되면 다형성이 부풀려짐
	- 겹친 핵 분할 오류, 배율 미정규화 시 크기 특징 왜곡

실험 5. 메틸화가 못 보는 공간 신호
* 질문: 같은 면역 비율이라도 배치가 예후에 추가 정보를 주나
* 공간 특징 (실험 4 결과 재사용 + 조직 영역 분류)
	- 종양 둥지 내 / 기질 내 림프구 밀도 비율 (염증형 대 배제형 대리 지표)
	- 림프구–종양세포 평균 거리
	- 면역 한랭 영역 수 (TRACERx 방식)
	- 림프 응집체 수 (TLS 후보)
	- 종양-기질 비율
	- [추가] 다형성 ④와 림프구 밀도의 영역 단위 공간 상관 (거친 종양 영역에 면역세포가 모이나, 피하나)
* Cox 모델 단계 비교 (TCGA-CDR 생존)
	- 임상 → + 메틸화 LF → + 공간 특징 → + 다형성 ④
* 확장: 같은 특징 위에 그래프 모델(SlideGraph+ 방식) vs attMIL

실험 6. 순환 없는 multi-omics 결합
* 타깃과 입력의 데이터 출처를 분리
	- 타깃 RNA 유래(ESTIMATE, 생존) → 입력 WSI + 메틸화 PCA·디컨볼루션 비율
	- 타깃 메틸화 유래 → 입력 WSI + RNA·단백질
* 09 ②④ 설계는 폐기

실험 7. 일반화 검증
* LUAD → LUSC, LUSC → LUAD
* BRCA 모델 → 폐암 적용
* CPTAC-LUAD/LSCC 외부 검증 (H&E·메틸화·단백체 짝 여부 먼저 확인)
* [추가] 다형성 ④ 지표의 코호트 간 분포 비교 (염색·스캐너 차이에 대한 안정성)

진행 순서
* 0 → 4 (HoVer-Net 처리를 슬라이드 처리와 동시에) → 1·2 → 3 → 5 → 6·7
	- [변경] 실험 4를 앞당김: 4b의 다형성 ④가 실험 2의 교란 변수, 실험 5의 공간 특징 재료로 쓰이므로
