# MIL pooling 방법 30개

#2026-10-06

---

A. 고정 규칙 풀링 (학습할 파라미터가 거의 없음)

1. Max pooling
- 가장 의심스러운 타일 하나의 점수만 보고 슬라이드 전체를 판정합니다. 썩은 사과가 하나라도 있으면 상자 전체가 불량이라는 논리입니다. 학습 신호가 타일 하나에서만 나와 데이터 효율이 낮고, 이상치 하나에 휘둘립니다.
→ 미세 전이처럼 작은 병변 하나만 찾으면 되는 검출 문제 (림프절 전이 유무)

2. Mean pooling
- 모든 타일을 똑같은 비중으로 평균 냅니다. 반 학생 전원의 점수를 평균 내서 반의 실력을 판단하는 것과 같아서, 무관한 지방이나 배경 타일까지 핵심 타일과 같은 무게로 섞여 신호가 희석됩니다.
→ 조직 전체에 고르게 퍼진 특징 (선암 대 편평세포암 같은 아형 분류, 슬라이드 전반의 염색 특성)

3. Sum pooling (Deep Sets, Zaheer 2017)
- 평균이 아니라 합계를 냅니다. 평균은 "얼마나 진한가"를, 합계는 "총 얼마나 많은가"를 말합니다. 같은 비율의 종양이라도 조직이 크면 합계가 커지므로, 개수나 총량에 민감합니다.
→ 총량이 의미 있는 문제 (종양 부담, 유사분열 총수). 단 조직 크기에 결과가 끌려가므로 생검 크기가 제각각이면 주의

4. Top-k mean pooling
- 가장 의심스러운 k개 타일의 평균을 냅니다. 한 명의 목격자만 믿는 대신 가장 확신하는 목격자 5명의 말을 평균 내는 것이라, max보다 우연한 이상치 하나에 덜 흔들립니다.
→ 병변이 작지만 한 타일보다는 넓은 문제 (고등급 영역 검출, MSI처럼 국소적이지만 여러 타일에 걸친 신호)

5. CHOWDER의 min-max pooling (Courtiol 2018)
- 가장 높은 점수 R개와 가장 낮은 점수 R개를 함께 봅니다. 재판에서 가장 강한 유죄 증거와 가장 강한 무죄 증거를 둘 다 듣는 것과 같습니다. "있다"의 근거와 "없다"의 근거를 동시에 쓰므로 적은 데이터에서도 비교적 안정적입니다.
→ 양성·음성 근거가 모두 의미 있는 문제, 데이터가 적은 검출·예후 과제 (중피종 예후 예측 MesoNet이 이 계열)

6. Log-sum-exp (LSE) pooling
- max와 mean 사이를 부드럽게 오가는 손잡이(r)가 있는 풀링입니다. r이 크면 max처럼, 작으면 mean처럼 행동합니다. 볼륨 노브를 돌려 "튀는 소리만 들을지, 전체 소리를 들을지"를 조절하는 셈입니다.
→ 병변이 국소적인지 미만성인지 미리 알 수 없는 문제

7. Noisy-OR pooling
- "적어도 하나가 양성일 확률" = 1 − (모든 타일이 음성일 확률의 곱)으로 계산합니다. 확률론적으로 깔끔하지만, 타일이 수만 개면 작은 확률들이 곱해지며 거의 항상 양성 쪽으로 포화되는 문제가 있습니다.
→ 타일 수가 적고 후보 영역이 이미 추려진 경우 (작은 생검, 미리 선별된 ROI 몇 개)

8. Generalized mean (GeM / power mean) pooling
- p제곱 평균의 p를 학습으로 정합니다. p=1이면 평균, p가 커지면 max에 가까워집니다. LSE와 같은 정신이지만 손잡이를 데이터가 직접 정하게 한다는 점이 다릅니다.
→ LSE와 같은 상황에서, 국소성 정도를 데이터로 배우게 하고 싶을 때

9. 타일 투표 / 양성 타일 비율 (Coudray 2018)
- 모든 타일에 슬라이드 라벨을 그대로 붙여 타일 분류기를 학습한 뒤, 타일 예측 확률을 평균 내거나 양성 타일의 비율을 셉니다. 선거에서 개표하듯 타일들이 투표하는 방식입니다. 양성 슬라이드의 음성 타일까지 양성으로 배우는 잡음 라벨 문제가 있습니다.
→ 형태 신호가 조직 대부분에 퍼진 문제 (폐암 아형, 일부 유전자 변이), 결과 자체가 "비율"인 문제

10. Distribution pooling (Oner 2020, 2023)
- 각 특징마다 평균 하나만 남기는 대신 히스토그램 전체를 남깁니다. 반 평균 70점이라는 숫자 대신 점수 분포 그래프를 보는 것이라, "모두 70점인 반"과 "절반은 100점, 절반은 40점인 반"을 구별할 수 있습니다. 저자들은 이 방식이 max나 mean 같은 점 추정 기반 풀링보다 담을 수 있는 정보량 측면에서 더 표현력이 높다는 것을 수학적으로 증명했습니다.
→ 이질성 자체가 중요한 문제, 비율 회귀 문제 (이 계열 모델로 조직 내 암세포 비율인 종양 순도를 예측한 연구가 있습니다) 

11. Multiple Instance Regression, primary instance (Ray & Page 2001)
- 연속값 정답이 가방 안의 "대표 인스턴스" 하나에 의해 결정된다고 가정하고, 그 대표를 찾아 회귀합니다. El Nahhas 논문이 인용한 고전 문헌입니다. 회귀판 max pooling이라고 보면 됩니다.
→ 연속값이 특정 한 지점의 측정으로 정해지는 문제 (흑색종 Breslow 두께처럼 가장 깊은 침윤 지점이 값을 정하는 경우)

B. 순서·시퀀스 기반

12. RNN aggregation (Campanella 2019, MIL-RNN)
- 먼저 max 기반 MIL로 슬라이드마다 가장 의심스러운 타일 S개를 고르고, 그 타일들의 특징을 RNN에 차례로 넣어 최종 판정합니다. 1차 면접으로 후보를 추린 뒤 2차 면접에서 후보들을 종합 평가하는 2단계 선발입니다. 타일에 원래 순서가 없는데 순서를 부여한다는 어색함이 있습니다.
→ 대규모 데이터의 임상급 검출 (전립선 생검, 기저세포암, 액와 림프절 전이 스크리닝)

C. Attention 계열

13. ABMIL (Ilse 2018)
- 타일마다 모델이 스스로 배운 중요도 점수를 매기고, 그 점수로 가중평균을 냅니다. 배심원이 증인마다 신뢰도를 매겨 말을 종합하는 방식이고, 신뢰도가 그대로 heatmap이 됩니다. max와 mean을 모두 포함하는 일반형입니다.
→ 범용 기본값. 분류와 회귀 모두 (El Nahhas의 CAMIL 회귀가 이 구조)

14. Gated attention (Ilse 2018)
- attention 점수를 계산할 때 tanh 갈래에 sigmoid "문(gate)"을 곱합니다. 중요도를 매길 뿐 아니라 "이 특징은 아예 꺼 버려라"를 표현할 수 있어서, 미묘한 신호를 구별하는 데 유리합니다.
→ 미세한 형태 차이로 판정해야 하는 문제 (CLAM이 기본으로 사용)

15. CLAM (Lu 2021)
- 클래스마다 attention 갈래를 따로 두고, 상위·하위 attention 타일로 가짜 라벨을 만들어 타일 특징 공간을 정돈하는 보조 학습을 붙입니다. 과목별로 담당 교사를 따로 두고, 수업 중 "이건 확실히 정답 예시, 이건 확실히 오답 예시"를 따로 정리하게 하는 셈입니다.
→ 다중 클래스 아형 분류, 데이터가 수백 장 수준인 문제 (신세포암 3분류, 폐암 아형)

16. DSMIL (Li 2021)
- 두 갈래로 작동합니다. 한 갈래는 max로 가장 결정적인 타일을 찾고, 다른 갈래는 다른 모든 타일이 그 결정적 타일과 얼마나 닮았는지로 attention을 매깁니다. 범인을 먼저 지목한 뒤 "범인과 비슷한 사람"을 공범 후보로 모으는 방식입니다. 여러 배율을 합치는 다중 스케일 버전도 있습니다.
→ 작은 양성 영역 검출에 강함 (Camelyon16 전이 검출)

17. ACMIL (Zhang 2023/2024)
- 기존 attention이 일부 판별적 인스턴스에만 몰려 과적합과 연결된다는 분석에서 출발해, 여러 attention 갈래로 다양한 판별 패턴을 잡고(MBA), attention 상위 K개 타일 일부를 무작위로 가려 그 몫을 나머지 타일에 나눠 주는 방식(STKIM)을 결합했습니다. 반에서 늘 손드는 학생만 시키지 말고, 그 학생을 가끔 가려서 다른 학생 말도 듣게 하는 것입니다.
→ 판별 패턴이 여러 종류인 이질적 종양, 과적합이 걱정되는 소규모 코호트 

18. MHIM-MIL (Tang 2023)
- attention이 분류하기 쉬운 타일에 편향되고 어려운 타일을 무시한다는 문제의식에서, 모멘텀 교사 모델이 attention 기반으로 쉬운 타일을 가리고 학생 모델이 남은 어려운 타일로 학습하게 합니다. 쉬운 문제는 빼고 오답 노트 문제만 풀게 하는 공부법입니다.
→ 경계가 애매한 병변, 쉬운 단서 하나가 학습을 지배하는 문제 (경계성 병변, 아형 감별) 

19. Additive MIL (Javed 2022)
- attention으로 가중한 뒤 슬라이드 벡터를 만드는 대신, 타일마다 최종 점수에 "더해지는 기여분"을 따로 계산해 합칩니다. 각 타일이 예측을 올렸는지 내렸는지, 얼마나 그랬는지가 정확히 분해됩니다. attention이 "어디를 봤나"만 말해 준다면, 이 방식은 "어느 방향으로 얼마나 밀었나"까지 말해 줍니다.
→ 해석이 중요한 회귀·바이오마커 과제 (어떤 영역이 점수를 올리고 내렸는지 검증해야 할 때)

D. 타일 간 관계·공간 맥락

20. TransMIL (Shao 2021)
- 타일들이 서로를 참고하게 하는 self-attention을 씁니다. ABMIL의 증인들이 각자 따로 증언했다면, 여기서는 증인들이 서로 이야기를 나눈 뒤 증언합니다. 계산량을 줄이려 Nyström 근사를 쓰고, 위치 정보를 넣는 PPEG 모듈을 둡니다. 데이터가 적으면 과적합되기 쉽습니다.
→ 타일 간 관계가 판정에 중요한 문제 (종양과 면역세포의 상호작용, 아형 분류)

21. Set Transformer의 PMA (Lee 2019)
- 학습 가능한 "질문 벡터"(seed) 몇 개가 타일 집합 전체에 attention을 걸어 요약을 만듭니다. 기자 여러 명이 각자 다른 질문을 들고 군중을 인터뷰하는 것과 같아서, seed가 여러 개면 서로 다른 측면의 요약이 여러 개 나옵니다.
→ 한 슬라이드에서 여러 패턴을 동시에 요약해야 하는 다중 과제 (여러 바이오마커 동시 예측)

22. DTFD-MIL (Zhang 2022)
- 슬라이드 하나를 무작위로 여러 개의 "가짜 가방"으로 쪼개 같은 라벨을 붙여 학습량을 늘리고(1단계), 각 가짜 가방의 요약 특징을 모아 다시 attention으로 합칩니다(2단계). 한 권의 책을 여러 장으로 나눠 읽고 각 장 요약을 다시 종합하는 방식입니다. 양성 영역이 아주 작으면 일부 가짜 가방에 병변이 없어 라벨이 틀어질 수 있습니다.
→ 슬라이드 수가 적은 코호트, 신호가 비교적 넓게 퍼진 문제

23. HIPT (Chen 2022)
- 16×16 → 256×256 → 4096×4096 픽셀 단위로 ViT를 계층적으로 쌓아, 세포 수준에서 조직 구조 수준까지 단계적으로 요약합니다. 단어 → 문장 → 문단 → 책 순서로 읽는 것과 같습니다.
→ 조직 구조(architecture)가 중요한 문제 (선 구조 형성, Gleason 패턴, 생존 예측)

24. ZoomMIL (Thandiackal 2022)
- 저배율에서 전체를 훑고, 중요한 곳만 골라 고배율로 확대하는 과정을 미분 가능하게 학습합니다. 병리의사가 4배로 훑다가 40배로 확대하는 진료 습관을 흉내 낸 것이라 계산도 절약됩니다.
→ 구조와 세포 모양을 둘 다 봐야 하는 등급 판정 (유방 병변 다단계 분류, 전립선 등급)

25. Patch-GCN (Chen 2021)
- 인접한 타일끼리 선으로 연결해 그래프를 만들고, 그래프 신경망으로 이웃끼리 정보를 주고받게 합니다. 동네 주민들이 옆집과 소식을 나누며 동네 분위기가 형성되는 것과 같습니다.
→ 공간 배치가 의미 있는 생존 예측, 면역세포가 종양 가장자리에 머무는지 안으로 침투했는지 같은 문제

26. Context-aware CAMIL (Fourkioti 2024)
- 각 타일의 attention 점수를 주변 타일들의 attention 점수를 모아 다시 보정합니다. 혼자 수상해 보이는 타일이라도 이웃이 모두 정상이면 점수를 낮추는 식입니다. El Nahhas 논문의 CAMIL과 이름만 같고 전혀 다른 방법이니 주의하세요.
→ 비소세포폐암 아형 분류와 림프절 전이 검출처럼 종양과 인접 조직의 맥락이 오분류를 줄이는 문제 

27. Mamba 계열 (MamMIL, MambaMIL 등)
- Transformer는 타일 수의 제곱으로 계산량이 늘지만, 상태공간모델(Mamba)은 선형으로 늘어납니다. MamMIL은 Mamba가 원래 한 방향 1차원 시퀀스만 처리한다는 한계를 양방향 상태공간모델과 2D 맥락 블록으로 보완해, Transformer 기반 방법보다 적은 메모리로 인스턴스 간 의존성을 학습한다고 보고했습니다. 긴 책을 처음부터 끝까지 요약 노트를 갱신하며 읽는 방식입니다.
→ 고배율에서 타일이 수만 개 넘는 큰 슬라이드, GPU 자원이 제한된 환경 

E. 군집·프로토타입 기반

28. DeepAttnMISL (Yao 2020)
- 환자의 타일들을 형태가 비슷한 몇 개의 군집(표현형)으로 먼저 나누고, 군집마다 요약한 뒤 군집들에 attention을 걸어 합칩니다. 동네 주민을 직업별로 먼저 나누고, 직업군별 대표 의견을 모아 동네 성격을 판단하는 것입니다.
→ 조직 구성 비율이 예후를 좌우하는 생존 예측

29. PANTHER (Song 2024)
- 각 타일이 혼합분포에서 생성되었다고 가정하고, 혼합의 각 성분을 하나의 형태 원형(prototype)으로 보아 슬라이드를 훨씬 작은 원형 집합으로 요약합니다. 직관적으로 성분의 평균은 형태 예시를, 혼합 비율은 그 패턴이 슬라이드에서 차지하는 비중을 나타냅니다. 라벨 없이 만들어지는 요약이라 과제에 덜 묶입니다.
→ 데이터가 적은 생존·아형 분류, 그리고 "어떤 조직이 몇 % 있나"가 답에 직결되는 비율 문제 

F. 사전학습 슬라이드 인코더

30. Prov-GigaPath의 LongNet 슬라이드 인코더 (Xu 2024)
- 풀링 함수를 과제마다 처음부터 학습하는 대신, 대규모 데이터로 미리 학습된 슬라이드 수준 인코더를 가져다 씁니다. 타일 수준에서 DINOv2로 자기지도 학습한 뒤, LongNet과 마스크 오토인코더로 슬라이드 수준 자기지도 학습을 이어 가는 구조입니다. 기존 모델들이 슬라이드마다 일부 타일만 샘플링해 전체 맥락을 놓쳤다는 문제를 겨냥했고, 26개 과제 중 25개에서 최고 성능을 보고했습니다. 이미 수많은 책을 읽은 사서에게 새 책 요약을 맡기는 것입니다.
→ 라벨된 슬라이드가 적은 돌연변이·바이오마커 예측, 슬라이드 전체 맥락이 필요한 문제 

한눈에 고르는 기준

문제 유형별로 다시 묶으면, 작은 병변 하나를 찾는 검출 문제라면 max, top-k, DSMIL, MHIM-MIL 쪽이 맞고, 조직 전체에 퍼진 특징이라면 mean, 타일 투표, ABMIL이 자연스럽습니다. 값 자체가 비율이나 연속값인 회귀 문제라면 attention 가중평균, distribution pooling, PANTHER처럼 "얼마나 섞여 있나"를 보존하는 방식이 원리적으로 잘 맞고, 공간 배치가 중요하면 Patch-GCN, context-aware CAMIL, TransMIL, 배율이 중요하면 ZoomMIL이나 HIPT가 후보입니다. 데이터가 적을 때는 CLAM, DTFD-MIL, PANTHER, ACMIL이 과적합을 다루는 장치를 갖고 있습니다.

지금까지 읽으신 논문들과 연결하면, El Nahhas 논문이 예측한 백혈구 비율(LF)이나 기질 비율(SF)처럼 메틸화에서 나온 "세포 구성 비율"을 회귀로 맞히려 한다면, max 계열은 원리적으로 맞지 않습니다. 비율은 "어딘가에 하나라도 있나"가 아니라 "전체에 얼마나 퍼져 있나"이니까요. 그런 문제에는 ABMIL 회귀를 기본선으로 두고, 형태 원형의 비율을 명시적으로 뽑는 PANTHER나 분포 전체를 보존하는 distribution pooling을 비교 대상으로 삼아 보는 것이 자연스러운 설계일 것 같습니다.
