# 폐암 데이터셋

#2026-11-01

---

```
전체 {'LUAD': 584, 'LUSC': 504} → 코호트(RNA) {'LUAD': 517, 'LUSC': 501}
```

TCGA-LUAD, LUSC에서 각각 584장, 504장을 다운로드하였다. 분석 코호트는 RNA가 존재하는 517+501명을 사용하였다. (다운로드 방식: GDC API)

```
          LUAD   LUSC
MAF        465    463
Meth       414    347
RNA        474    476
RPPA       328    304
miRNA      467    460
```

GDC 포털에서 5가지 오믹스를 다운받았다.  데이터가 존재하는 대상자는 이와 같다. 

```
LUAD: 환자 414 | 탐침 486,427 → cg·마스크·성염색체 442,243 → 결측 400,772 | 대체 0.53%
LUSC: 환자 347 | 탐침 486,427 → cg·마스크·성염색체 442,243 → 결측 397,085 | 대체 0.77%
```
