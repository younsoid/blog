# Paper #2 Whole slide images reflect DNA methylation patterns of human tumors

#2026-10-05

---

### 1. Introduction

* DNA 메틸화 = 유전자 발현 조절 핵심 후성유전 기전
	- 과메틸화(hyper)·저메틸화(hypo) 모두 암에서 발현 교란
	- 이상 메틸화 = 가장 흔한 암 분자 변화, 바이오마커·드라이버로 주목
* TCGA: 10,000+ 샘플 메틸화 어레이 → 방대한 데이터
* 메틸화의 임상 적용 한계
	- 질환마다 바이오마커 성능 제각각, 검증 진행 중
	- 결과까지 수주 소요 → 치료 결정 지연
* 반면 WSI = 암 의심 시 거의 항상 확보, 조직 구조·세포 구성 정보 풍부
* 기존 WSI 계산병리 연구
	- C-Path(유방암): 생존 예측 최고 특징이 종양이 아닌 주변 기질에서 나옴
	- 교모세포종: 조직 이미지 + 유전체 → CNN 생존 예측
	- SPM(spatial pyramid matching): 핵 형태 통계로 다중 위치·스케일 맥락 특징 구성
* 목표: 메틸화 패턴이 WSI에 반영되는지, 고전 머신러닝으로 예측 가능한지
* 대상: 조직 기원이 전혀 다른 두 암 = 신경교종(glioma), 신세포암(RCC)

<grayblock>

- 이상 메틸화가 암 유발할수 있거나 예후 예측에 쓸수있다.
- 그렇지만 메틸화로 암을 진단하기에는 아직 명확한 마커가 발굴된바가 없다. 암 진단에는 보통 WSI를 쓴다.
  - WSI로 메틸레이션을 예측할수있을까?
- 기존 wsi 연구의 진행 사항은
  - 유방암 이미지(암 상피와 주변 기질)에서 특성을 추출해서 생존 분석했는데 생존을 가장 잘 예측이 특징은 암세포 자체가 아니라 그 옆의 기질이었다.
  - 조직 이미지와 유전체 바이오마커를 합쳐 합성곱 신경망(CNN)으로 생존을 예측할수가 있다. 즉 이미지, 유전체, 딥러닝 분석이 가능하다.
  - 이미지 스캐너와 환자 개인의 특성에 의한 배치를 없애기 위해서 공간 피라미드 매칭(SPM)을 도입할수가 있다.
- 메틸화 같은 분자 정보와 WSI의 조직 정보가 있을때
  - 두 정보 사이의 관계는? 통합해서 사용하려고 하는데 같은 것을 말하고 있다면 하나로 다른 하나를 대신할 수 있고, 전혀 다른 것을 말하고 있다면 둘을 합쳤을 때 시너지가 클 것.
  - 기존 연구는 이미지로 생존을 예측하거나 이미지와 유전체를 합쳐 생존을 예측했고 "이미지 자체가 메틸화를 얼마나 반영하는가"라는 질문은 다루지 않았다.
- 메틸화 패턴이 WSI에 반영되는지, 반영된다면 어떻게 반영되는지를 확인한다.
  - "핵 면적의 분포", "핵 장축의 사분위 범위"처럼 사람이 이해할 수 있는 형태 특징을 입력으로 한 머신러닝을 사용해서 해석가능성도 본다.

cf) 암의 기작 관련 pathway와 메틸레이션의 작동영향을 많이 받는 pathway를 봣을때 교집합은? 그리고 그 pathway가 많이 관여하는 암종을 고르면?

- 연구 기작은 신경교종과 RCC 샘플에서 WSI로부터 뽑은 형태 특징으로 메틸화 상태를 예측.
- 비슷한 메틸화 패턴을 가진 유전자들을 묶어 군집 단위로 예측하면 성능이 크게 좋아지는걸 확인한다. 그리고 잘 예측되는 유전자들이 어떤 생물학적 경로에 속하는지 경로 분석으로 본다.

</grayblock>

### 2. Background

2.1 MethylMix와 DM 값
* 저자 그룹이 개발한 beta mixture model 기반 메틸화 드라이버 유전자 탐지 도구
* 정상 vs 암 메틸화 + 유전자 발현 통합
	- 조건: 정상 대비 차등 메틸화 + 발현까지 예측하는 유전자
* 출력 = DM(Differential Methylation) 값 = 비정상 상태 - 정상 상태
	- 양수 = 과메틸화, 음수 = 저메틸화, 0 = 정상
* 활용 사례
	- 두경부암: DM 기반 5개 아형 → HPV·흡연 원인군과 더 잘 맞음
	- 편평세포암: NSD1 비활성 저메틸화 아형
	- 단백체 데이터로 후보 추가 압축 가능

<grayblock>

- 전사적으로 예측력이 있는(transcriptionally predictive) 유전자를 MethylMix로 식별 가능하다.
  - 메틸화가 되었다고 해서 발현이 무조건 바뀌는게 아닌데, 실제로 발현량을 바꾸는 메틸레이션을 식별하는 툴이 MethylMix이다. 
  - beta mixture model을 메틸레이션 데이터에 적용해서 DM 값(Differential Methylation value)을 낸다. 양수면 정상 대비 과메틸화다.
  - DM 값으로 기존 유전자 발현 기반 subtype과 다른 subtype을 식별한 연구도 있다.

</grayblock>

2.2 형태계측(morphometric) 특징
* 세포 단위 측정값: 핵 면적·장단축·곡률·질감·강도, 세포질 강도·기울기 등
* 맥락(contextual) 특징: 세포 구성·이질성 요약
* 환자 단위로 요약 통계화: mean, median, SD, skewness, kurtosis, IQR

<grayblock>

- 크기, 모양 특징
  - 종횡비(aspect ratio): 핵이 동그란지 길쭉한지
  - 곡률(curvature): 윤곽선이 얼마나 급하게 휘는지 / 굽힘 에너지(bending energy): 윤곽선 전체가 얼마나 구불구불한지 / 볼록성 편차(deviation from convexity)는 핵 가장자리가 움푹 들어간 곳이 있는지. (정상 세포의 핵은 매끈하고 둥근데 암세포의 핵은 울퉁불퉁하고 찌그러지는 경우가 많음)
- 색과 무늬
  - 핵 안의 염색 강도(intensity): DNA가 얼마나 빽빽하게 뭉쳐 있는지
  - 기울기(gradient): 밝기가 얼마나 급격하게 바뀌는지 즉 경계나 내부 구조가 얼마나 또렷한지
  - 질감 특징(texture feature 0~11): 핵 안의 명암이 고르게 퍼져 있는지, 알갱이처럼 얼룩덜룩한지 (병리의사가 "염색질이 거칠다"거나 "미세 과립상이다"라고 말하는 것을 수치화)
    - 핵 안의 명암 무늬는 염색질이 어떻게 접혀 있느냐를 반영하는데, 메틸화가 염색질 구조와 엮여 있다는게 논문에서 나온다고함.
- 등등 35개 측정값 + 6가지 통계 + 맥락 특징 8개 -> 환자당 약 200개 feature
- 환자 수: 신경교종 342명, RCC 326명

</grayblock>

2.3 대상 암
* 신경교종
	- 신경교 줄기·전구세포 유래, 원발성 뇌종양 사망 대부분
	- 조직형: 성상세포·핍지교세포·뇌실막세포종
	- WHO II–III = LGG, IV = GBM (괴사·미세혈관 증식으로 구분)
	- WHO 2016: 조직 + 분자 통합 분류 강조
* RCC
	- 신세뇨관 상피 유래, 신장암 90% 이상, 10개 이상 아형
	- 투명세포·유두상·혐색소·집합관·미분류, 투명세포형(ccRCC) 최다

### 3. Method

3.1 데이터
* 메틸화: Illumina 450K, NCI GDC
	- TCGA glioma 932명, ccRCC 519명
* WSI: GDC 포털
* 메틸화 + 형태 특징 둘 다 있는 환자만 분석
	- glioma 342명, RCC 326명

3.2 메틸화 상태 정의 (MethylMix)
* 드라이버 유전자 선별 → 환자별 DM 값 행렬
* 3상태: 과메틸화(+) / 저메틸화(-) / 정상(0)
* 필터링
	- 한 상태가 환자 90% 초과 → 제외 (클래스 불균형 방지)
	- 상태가 1개뿐이거나 3개인 유전자 → 제외
	- 정확히 2상태 유전자만 → 이진 분류로 통일

<grayblock>

- 메틸화, 슬라이드이미지: NCI의 GDC포털에서 가져옴
  - 양쪽 모두있는 신경교종 342명, RCC 326명
- MethylMix DM값 필터링
  - 정상/암 라벨이 전체 환자의 90%를 넘게 차지하는 유전자는 제외. (100명 중 92명이 정상이면 모델이 정상이라고만 답해도 정확도 92%가 나옴)
  - 정상/암2종 중 하나뿐이거나 셋 모두 나타나는 유전자 제외 (이진분류여야 정확도를 AUC나 F1로 볼수있음)
- 신경교종에서 927개, RCC에서 366개 유전자가 사용됨.

</grayblock>

3.3 유전자 군집화
* 비슷한 메틸화 패턴 유전자끼리 계층적 군집화
* 군집 수: 히트맵 육안 확인 + silhouette score → 5개 선택
* 군집 DM 값 = 군집 내 유전자 DM 평균
* Gaussian mixture model로 최적 임계값 → high/low 이진화
[보충 그림 1]

3.4 이미지 특징 추출
* ref.16(Chang et al., morphometric context) 방법으로 추출된 특징 사용
* 환자당 세포 형태 특징 35개 + 맥락 특징 8개
* 6개 요약 통계로 확장 (mean, median, SD, skewness, kurtosis, IQR)
[보충 표 1]

3.5 다변량 모델링
* 입력 = 형태 특징, 정답 = 유전자(또는 군집)별 이진 메틸화 상태
* 유전자·군집마다 개별 분류기 = multitask + multivariate 분류
* 30회 무작위 분할: 학습 75% / 테스트 25%
* 학습셋 내 5-fold CV로 하이퍼파라미터·정규화 강도 선택
* 특징 많고 샘플 적음 → 정규화로 과적합 억제
* 모델 6종 (scikit-learn)
	- 로지스틱 회귀(lasso), 랜덤포레스트(트리 수)
	- SVM(linear/rbf 커널, C), AdaBoost(학습률, 추정기 수)
	- Naive Bayes, 2층 완전연결 신경망(학습률)
[그림 1] 전체 파이프라인 (WSI → 특징 → 모델 ← DM 값 ← MethylMix)

3.6 평가
* 지표: accuracy, precision, recall, F1, ROC·AUC, PR curve
* 과제별로 30회 결과 평균
* 로지스틱 회귀 계수로 특징 중요도 순위화
* 비교: 임상 특징만(나이·성별·병기) vs 임상 + 형태 특징

<grayblock>

- dm 값으로 유전자 클러스터링
  - hierarchical clustering 썼고 k는 heatmap 육안 + silhouette score 사용해서 k=5로 정함.
  - 클러스터 마다 dm 평균을 구한 다음에 높/낮음 라벨을 할당. 이진 분류에는 Gaussian mixture model(GMM)을 사용.
- 이미지 특징 추출
  - 형태계측 맥락(morphometric context) 방법을 차용
  - 세포마다 35가지 형태 특징 + 슬라이드 전체의 세포 구성을 요약한 맥락 특징 8개를 보고 6개 요약으로 줄여서 보기.
- 다변량 모델링
  - 신경교종 342명과 RCC 326명에 대해, 유전자 마다 분류기를 학습시킴. (다중 과제 multitask, 다변량multivariate 분류 문제)
  - 입력은 환자의 feature, 출력은 메틸화 상태 이진분류.
  - *6개 모델
  - **평가: accuracy, precision, recall, F1, ROC 곡선 / AUC, precision-recall(PR) 곡선

</grayblock>

### 4. Results

4.1 신경교종 유전자 단위 예측
* MethylMix → 927개 드라이버 유전자
* 6모델 중 Naive Bayes만 평균 AUC < 0.7 → 이후 제외
* 나머지 5모델 평균: AUC 0.74, F1 0.64
* 모든 모델에서 AUC·F1 > 0.8 유전자 8개
	- CDK4, COL5A1, CPA4, CSTB, MMP7, MYCBP, PPIC, TMEM59
* 대표 유전자
	- CDK4: G1→S 세포주기 진행, 신경교종에서 자주 변이
	- MYCBP: C-MYC 결합 단백질, S기에 핵 이동, 위암 침윤·이동 촉진
	- CDK4·MYCBP: LR·SVM·NN에서 AUC > 0.94, F1 > 0.84
	- TMEM59(DCF1): 신경줄기세포 분화, 신경교종 세포주 세포사멸, 전 모델 AUC > 0.91
	- MMP7: ECM 분해로 침윤, SVM AUC 0.92 / F1 0.85
[그림 2] (a 모델별 5개 지표 violin plot, b CDK4·MYCBP ROC·PR)

4.2 신경교종 군집 단위 예측
* 군집 단위로 묶자 성능 크게 향상
* cluster 2 제외 모든 군집 AUC·F1 > 0.8
[그림 3] (a 계층적 군집 히트맵 hc3~hc7, b hc5 군집별 ROC·PR·violin)

4.3 RCC 예측

	- DAK, ITPRIP, LCP1, TM4SF19, TMEM200A

#생각
- WSI로 저메틸/고메틸을 예측했다.
- 근데 저메틸/고메틸 정의를 단순 beta 값이 아니라 MethylMix라는 도구를 써서 fine 하게 라벨링을 했고
- 유전자 필터링 및 유전자 클러스터 찾기도 MethylMix를 사용했는데
  - WSI로 gene 별 예측성능보다 WSI로 gene 클러스터 별 예측성능이 더 높았다.
  - 그중 예측성능 높았던 gene 클러스터가 혈관신생 경로와 연관있었다.
- 나이, 성별, 병기만 쓴 모델보다 형태 특징을 더하면 훨씬 잘 맞혔다
- 두 암 모두에서 중요했던 특징 핵 크기·모양이 얼마나 들쭉날쭉한가였다.
- 이게 끝인건데 유의미한 발굴이 있다기보다는 슬라이드 형태 안에 메틸화 정보가 들어 있다는 것을 정량적으로 보였다. 나이, 성별, 병기만으로는 잘 안 맞던 것이 형태를 넣자 맞기 시작했으니까 형태가 임상 정보로는 설명되지 않는 메틸화 정보를 담고 있다는 증거가 된다.
- 모델, 평가 방법을 다양하게 써서 참고하기는 좋은 방법론이다.

*모델별 설명
- 첫째는 lasso 정규화를 건 로지스틱 회귀입니다. 각 형태 특징에 가중치를 곱해 더한 점수를 만들고, 그 점수를 0과 1 사이 확률로 바꿔 "과메틸화일 확률"을 내놓는 가장 단순하고 해석하기 쉬운 모델입니다. lasso는 가중치들의 절댓값 합에 벌칙을 주는 방식인데, 이 벌칙의 특이한 성질은 쓸모없는 특징의 가중치를 아예 정확히 0으로 만들어 버린다는 것입니다. 200여 개 특징 중 정말 중요한 몇 개만 남기는 자동 선별 효과가 있어서, 특징이 많고 환자가 적은 이 연구에 잘 맞습니다. 나중에 특징 중요도를 이 모델의 가중치로 매기는 이유도 여기에 있습니다.
- 둘째는 랜덤 포레스트입니다. "핵 면적 중앙값이 이보다 크면 왼쪽, 작으면 오른쪽" 같은 질문을 연달아 던지는 의사결정 나무를 수백 그루 만들되, 나무마다 환자와 특징을 조금씩 다르게 뽑아서 학습시킵니다. 그리고 모든 나무의 투표로 답을 정합니다. 한 그루는 변덕스러워도 숲 전체의 다수결은 안정적이라는 원리입니다. 나무를 몇 그루 심을지를 손잡이로 조정했습니다.
- 셋째는 서포트 벡터 머신(SVM)입니다. 두 상태의 환자들을 형태 특징 공간에서 가르는 경계선을 긋되, 경계선과 양쪽에서 가장 가까운 환자들 사이의 여백이 최대가 되도록 긋습니다. 아슬아슬하게 가르는 선보다 넉넉하게 가르는 선이 새 환자에게도 잘 통할 것이라는 생각입니다. 커널을 linear로 하면 곧은 경계선을, rbf로 하면 구불구불한 경계선을 그을 수 있는데, 어느 쪽이 나은지와 함께 오분류를 얼마나 허용할지(정규화 상수)를 손잡이로 골랐습니다.
- 넷째는 AdaBoost입니다. 아주 약한 규칙(예를 들어 질문 하나짜리 나무)을 하나 만들고, 그것이 틀린 환자들에게 가중치를 높인 뒤 다음 규칙은 그 어려운 환자들을 더 신경 쓰도록 만듭니다. 이걸 반복해 약한 규칙들을 쌓아 올리면, 각자 틀린 부분을 서로 보완하는 강한 분류기가 됩니다. 오답 노트를 계속 보충해 가는 공부법과 비슷합니다. 학습률과 규칙의 개수를 조정했습니다.
- 다섯째는 나이브 베이즈입니다. 각 특징이 정답과 어떤 관계인지를 따로따로 계산한 뒤 그것들을 곱해서 결론을 내는데, 이때 "모든 특징은 서로 독립적이다"라는 순진한(naive) 가정을 합니다. 그런데 이 연구의 특징들은 서로 강하게 얽혀 있습니다. 같은 핵 면적에서 나온 평균과 중앙값은 거의 같은 이야기를 하고, 장축과 면적도 함께 움직입니다. 독립 가정이 크게 어긋나면 같은 증거를 여러 번 세는 셈이 되어 확신만 과해지고 판단이 왜곡됩니다. 결과에서 나이브 베이즈만 평균 AUC가 0.7에 못 미쳐 제외된 것은 이 구조적 약점과 잘 맞아떨어집니다. 다만 성적을 보고 나서 탈락시킨 것이므로, 이후 "모든 모델에서 잘 예측된 유전자"라는 표현의 "모든 모델"은 처음 정한 여섯이 아니라 살아남은 다섯이라는 점을 기억해야 합니다.
- 여섯째는 2층 완전연결 신경망입니다. 입력 특징들을 섞어 중간 표현을 만들고, 그것을 다시 섞어 답을 내는 작은 신경망입니다. 특징들 사이의 복잡한 조합을 잡아낼 수 있지만, 데이터가 적으면 과적합되기 쉽습니다. 손잡이로는 학습률을 조정했습니다.

**평가 방법별 설명

- 모델의 성적을 매기는 지표는 accuracy, precision, recall, F1, ROC 곡선과 AUC, precision-recall(PR) 곡선입니다. 이 지표들을 이해하려면 먼저 네 칸짜리 표를 떠올리면 됩니다. 실제로 과메틸화인 환자를 과메틸화로 맞히면 참양성, 정상인 환자를 정상으로 맞히면 참음성, 정상인데 과메틸화라고 하면 거짓양성, 과메틸화인데 정상이라고 하면 거짓음성입니다.
- 정확도(accuracy)는 전체 중 맞힌 비율입니다. 가장 직관적이지만, 앞서 본 대로 한쪽 상태가 많으면 부풀려지기 쉽습니다. 그래서 90% 필터를 걸었지만, 80 대 20 정도의 불균형은 여전히 남아 있을 수 있습니다.
- 정밀도(precision)는 "모델이 과메틸화라고 한 환자 중 진짜 과메틸화인 비율"입니다. 양치기 소년처럼 늑대가 왔다고 자주 외칠수록 떨어집니다. 재현율(recall)은 "진짜 과메틸화 환자 중 모델이 찾아낸 비율"입니다. 늑대가 왔는데 놓칠수록 떨어집니다. 둘은 줄다리기 관계라서, 조금만 의심돼도 과메틸화라고 하면 재현율은 오르지만 정밀도는 떨어지고, 아주 확실할 때만 그렇다고 하면 반대가 됩니다. F1 점수는 이 둘의 조화평균으로, 둘 중 하나라도 낮으면 같이 낮아지게 만들어 한쪽만 극단적으로 좋은 모델에 속지 않게 해 줍니다.
- ROC 곡선과 AUC는 기준선에 따른 변화를 한 번에 봅니다. 모델은 사실 "과메틸화일 확률 0.73"처럼 확률을 내놓고, 이것을 몇 이상이면 과메틸화로 볼지는 우리가 정합니다. 기준선을 1에서 0까지 내려가며 그때마다 민감도(재현율과 같은 것)와 특이도(정상 환자를 정상이라고 맞히는 비율)를 찍어 이은 것이 ROC 곡선입니다. 곡선 아래 면적인 AUC는 직관적으로 이렇게 해석할 수 있습니다. 과메틸화 환자 한 명과 정상 환자 한 명을 무작위로 뽑았을 때, 모델이 과메틸화 환자에게 더 높은 확률을 줄 가능성입니다. 동전 던지기 수준이면 0.5, 완벽하면 1입니다. 그래서 RCC의 평균 AUC 0.58은 "동전 던지기보다 조금 나은 수준"으로, 신경교종의 0.74는 "분명한 신호가 있는 수준"으로 읽을 수 있습니다.
- PR 곡선은 기준선을 바꿔 가며 정밀도와 재현율을 찍은 것입니다. ROC가 두 상태를 대칭적으로 다루는 반면, PR 곡선은 관심 있는 쪽(양성)을 얼마나 잘 찾는지에 집중합니다. 양성이 드물 때 ROC는 낙관적으로 보이기 쉬운데 PR 곡선은 그 약점을 드러내 주므로, 두 곡선을 함께 그린 것은 좋은 선택입니다. 결과 그림들에서 ROC와 PR이 나란히 있는 이유가 이것입니다.
- 각 과제의 성적은 30번 분할의 평균으로 보고합니다. 그리고 로지스틱 회귀에 대해서는 특징 중요도 분석을 덧붙였습니다. lasso 로지스틱 회귀에서 가중치의 크기는 그 특징이 판단에 얼마나 영향을 주는지를 나타내므로, 이를 순위로 매겨 상위 25%를 그림 7에 정리했습니다. 이 해석이 공정하려면 특징들의 단위가 통일되어 있어야 합니다. 핵 면적은 수백 단위, 종횡비는 1 근처 숫자라서, 표준화하지 않으면 가중치 크기가 단위 차이에 휘둘립니다. 원문에는 표준화 여부가 명시되어 있지 않아 공개 코드에서 확인해 볼 만합니다. 또 lasso는 서로 비슷한 특징들 중 하나만 골라 남기고 나머지를 0으로 만드는 경향이 있어서, 순위에서 빠진 특징이 실제로는 남은 특징만큼 중요할 수도 있습니다. 예를 들어 핵 장축 IQR이 뽑혔다면, 그와 거의 같이 움직이는 핵 둘레 IQR은 중요하지 않아서가 아니라 자리를 양보해서 빠졌을 수 있습니다.
