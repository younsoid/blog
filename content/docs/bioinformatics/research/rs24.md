### 1. GDC 파일 목록과 코호트

```
입력                  크기               파일                          최초 출처
GDC 파일 목록 조회     9,793행            (GDC API 응답)                 GDC API files 엔드포인트, TCGA-LUAD·LUSC
                                                                       자료형: Gene Expression Quantification,
                                                                       miRNA Expression Quantification,
                                                                       Masked Somatic Mutation,
                                                                       Protein Expression Quantification,
                                                                       Methylation Beta Value, Slide Image

출력                  크기               파일                          내용
GDC 파일 목록         9,793행 × 13열      data\manifest\gdc_files.csv   파일 × 환자 × 표본 한 줄 (파일 ID, 이름, 크기,
                                                                       md5, 자료형, 플랫폼, 실험 방식, 워크플로,
                                                                       조직형, 환자·표본 바코드, 표본 유형, 층)
코호트                950명               data\manifest\cohort.csv      DX 슬라이드와 원발 종양 RNA를 모두 가진 환자,
                                                                       층별 보유 여부
```

분석 대상을 처음부터 하나의 기준으로 정해야 이후 모든 단계의 환자가 일치한다. 특히 이 연구는 병리 이미지와 오믹스를 함께 다루므로, 두 자료를 모두 가진 환자를 코호트로 정할 필요가 있다. GDC API로 TCGA-LUAD·LUSC의 RNA, miRNA, 체세포 변이, RPPA, DNA 메틸화, 병리 슬라이드 파일 목록을 조회하였다(9,793행; 한 파일이 종양·정상 표본에 함께 걸리면 표본마다 한 행). 이 중 진단용 FFPE 슬라이드(DX)만 병리 이미지로 사용하고 동결 절편 슬라이드는 제외하였으며, 메틸화는 450K 플랫폼만 남겼다. 원발 종양 표본 기준으로 하나 이상의 자료를 가진 환자는 LUAD 571명, LUSC 504명이었다.

```
                                  LUAD   LUSC   합계
원발 종양 자료가 있는 환자          571    504   1075
  RNA 보유                         517    501   1018
  DX 슬라이드 보유                  478    478    956
  코호트 (DX + RNA)                474    476    950
  제외: RNA만 있음 (DX 없음)         43     25     68
  제외: DX만 있음 (RNA 없음)          4      2      6
  제외: 둘 다 없음                   50      1     51
```

병리 이미지 분석과 오믹스 분석이 같은 환자에서 이뤄지도록, 진단용 슬라이드와 원발 종양 RNA-seq을 모두 가진 LUAD 474명, LUSC 476명(총 950명)을 코호트로 정하였다. RNA는 있으나 진단용 슬라이드가 없는 환자(LUAD 43명, LUSC 25명), 슬라이드는 있으나 RNA가 없는 환자(4명, 2명), 둘 다 없는 환자(50명, 1명)는 제외하였다.

RNA 보유 환자(1,018명) 중 93%가 진단용 슬라이드도 갖고 있어, 두 자료를 모두 요구해도 표본 손실은 7%(68명)에 그친다. LUAD에서 RNA와 슬라이드가 모두 없는 환자가 50명으로 LUSC(1명)보다 많은데, 이들은 메틸화나 변이 등 다른 자료만 있는 환자로 RNA 기반 분석에는 처음부터 쓸 수 없다. 이후 모든 단계는 이 950명 중 표본 품질 기준(Do_not_use)을 통과한 환자를 분석 대상으로 한다(4번).

### 2. 환자당 층별 파일 선택과 다운로드

```
입력                  크기               파일                          최초 출처
GDC 파일 목록         9,793행             data\manifest\gdc_files.csv   1절
코호트                950명               data\manifest\cohort.csv      1절

출력                  크기               파일                                       내용
사용 파일 목록         4,198개             data\manifest\files_used.csv               환자 × 층 한 줄 (고른 파일과 디스크 경로)
RNA 원자료            950개               omics_raw\rna\<환자>.tsv                   GDC STAR - Counts 파일
miRNA 원자료          927개               omics_raw\mirna\<file_id>\*.txt            GDC BCGSC miRNA Profiling 파일
변이 원자료           928개               omics_raw\maf\<file_id>\*.maf.gz           GDC Masked Somatic Mutation 파일
메틸화 원자료         761개               omics_raw\methylation\raw\<환자>.txt        GDC 450K Methylation Beta Value 파일
RPPA 원자료           632개               omics_raw\rppa\<file_id>\*.tsv             GDC RPPA 파일
```
GDC에는 한 환자의 같은 층에 원발 종양 파일이 여러 개 있는 경우가 있다(같은 종양 표본의 재측정, 서로 다른 aliquot, 서로 다른 정상 대조 표본과 짝지은 변이 호출 등). 환자마다 파일 하나만 쓰는 규칙을 정해 두지 않으면 같은 환자가 중복되거나 실행마다 다른 파일이 선택될 수 있다.

코호트 환자의 원발 종양 파일 중 층마다 환자당 하나를 골랐다. 선택 규칙은 표본 바코드, 파일 이름 순으로 정렬한 뒤 첫 번째 파일을 쓰는 것으로, 실행할 때마다 같은 파일이 선택된다. miRNA는 BCGSC miRNA Profiling 워크플로의 파일만, 메틸화는 450K 파일만 대상으로 하였다. 고른 파일 4,198개 중 디스크에 없던 파일은 GDC에서 받아 md5로 확인하였다.

```
              후보 파일   보유 환자   파일 2개 이상 환자 (최대)   코호트 대비(%)
RNA   LUAD       497        474           12 (3)                100.0
      LUSC       486        476           10 (2)                100.0
miRNA LUAD       473        467            3 (3)                 98.5
      LUSC       460        460            0                     96.6
변이  LUAD       518        465           22 (6)                 98.1
      LUSC       513        463           49 (3)                 97.3
메틸화 LUAD      429        414           11 (3)                 87.3
      LUSC       347        347            0                     72.9
RPPA  LUAD       328        328            0                     69.2
      LUSC       304        304            0                     63.9
```

파일이 여러 개인 환자는 변이에서 가장 많았고(LUAD 22명, LUSC 49명), 대부분 같은 종양 표본(예: TCGA-21-1076-01A)에 대해 변이 호출 파일이 여럿인 경우였다. RNA와 LUAD 메틸화에도 10명 안팎이 있었고, RPPA는 모든 환자가 파일 하나만 가졌다. 받은 원자료 파일은 층마다 형태가 달랐다. RNA는 유전자 약 6만 개의 read count와 TPM, miRNA는 성숙 miRNA 1,881개의 read count와 RPM, 변이는 환자당 수백 개 변이의 140여 개 주석 열, RPPA는 항체 487개의 발현값, 메틸화는 탐침 486,427개의 β값으로 이루어져 있었다.

RNA·miRNA·변이는 코호트의 97% 이상이 보유하였으나, 메틸화는 LUAD 87.3%, LUSC 72.9%, RPPA는 69.2%, 63.9%만 보유하였다.

파일이 여러 개인 환자는 층마다 최대 49명(LUSC 변이)으로 코호트의 10% 이내이고, 같은 종양 표본의 재측정이 대부분이어서 선택 규칙이 결과에 미치는 영향은 작을 것으로 보인다. 다만 이 규칙은 품질이 아니라 이름 순서로 고르는 것이므로, 변이처럼 중복이 많은 층에서는 선택된 파일이 다른 파일과 다른 결과를 줄 가능성이 남는다. 층마다 보유 환자가 다르므로, 층 간 비교(02)는 모든 층을 가진 공통 환자에서 수행해야 하며, 메틸화를 주 층으로 쓰면 LUSC 환자의 약 4분의 1이 해당 분석에서 빠진다.

### 3. 오믹스 표

```
입력                  크기               파일                                       최초 출처
RNA 원자료            950개               omics_raw\rna\<환자>.tsv                   GDC Gene Expression Quantification (STAR - Counts)
miRNA 원자료          927개               omics_raw\mirna\<file_id>\*.txt            GDC miRNA Expression Quantification (BCGSC)
변이 원자료           928개               omics_raw\maf\<file_id>\*.maf.gz           GDC Masked Somatic Mutation
RPPA 원자료           632개               omics_raw\rppa\<file_id>\*.tsv             GDC Protein Expression Quantification (RPPA)

출력                  크기                    파일                              내용
RNA TPM               유전자 60,660 × 950명    data\omics\rna_tpm.parquet        tpm_unstranded 값
유전자 주석           60,660개                 data\omics\genes.csv              gene_id, gene_name, gene_type (GENCODE v36)
비동의 변이           221,514행 (922명)        data\omics\maf_nonsyn.parquet     변이 한 줄 (유전자, 변이 종류, 아미노산 변화, 환자)
MAF 보유 환자         928명                    data\omics\maf_patients.csv       변이가 없는 환자를 포함한 MAF 보유 목록
RPPA                  항체 468 × 632명         data\omics\rppa.parquet           protein_expression 값 (정리 전)
miRNA                 miRNA 1,881 × 927명      data\omics\mirna_rpm.parquet      log2(RPM + 1)
```

환자별로 흩어진 원자료 파일을 분석에 바로 쓸 수 있는 행렬로 합쳤다.

```
행렬                 모양                 행        환자   결측
RNA (TPM)            유전자 × 환자        60,660    950    0%
miRNA (log2 RPM+1)   miRNA × 환자          1,881    927    0%
비동의 변이          변이 한 줄씩        221,514    922    -
RPPA                 항체 × 환자            468    632    2.5%
```

RNA는 STAR 정량 파일의 tpm_unstranded 값으로 유전자 60,660개(단백질 코딩 19,962개 포함) × 950명 행렬을 만들었다. miRNA는 성숙 miRNA 1,881개의 RPM을 log2(RPM + 1)로 변환하였으며, 이 중 평균 log2 RPM이 1 이상인 miRNA는 387개였다. RPPA는 항체 468개 × 632명 행렬로, 측정되지 않은 항체 때문에 2.5%가 결측이었다(정리는 10번).

변이는 MAF 파일의 전체 변이 296,382개 중 단백질 서열을 바꾸는 비동의 변이 9종 221,514개(74.7%)를 남겼다. 미스센스 변이가 190,996개(86.2%)로 대부분이었고, 넌센스(15,218개), 프레임시프트 결실(6,642개), 스플라이스 부위(5,338개) 변이가 뒤를 이었다. 환자당 비동의 변이 수는 중앙값 182개(사분위 106–295개, 범위 1–2,308개)였다. MAF 파일을 가진 928명 중 6명은 비동의 변이가 하나도 없어, 변이 표에는 922명이 나타난다.

RNA와 miRNA는 결측이 없어 그대로 분석에 쓸 수 있다. 환자당 비동의 변이 수가 1개에서 2,308개까지 크게 달라, 폐암에서 변이 부담의 개인 차이가 크다는 것을 보여 준다. 변이가 없는 6명은 MAF가 있으므로 "변이 없음"으로 판정해야 하며, 이를 위해 변이 상태(6번)는 변이 표가 아니라 MAF 보유 환자 목록(928명)을 기준으로 정의한다.

### 3-1. 메틸화 β 행렬과 QC

```
입력                  크기               파일                                       최초 출처
메틸화 원자료         761개 (탐침 486,427)  omics_raw\methylation\raw\<환자>.txt        GDC Methylation Beta Value
                                                                                  (Illumina Human Methylation 450, SeSAMe)
탐침 마스크           450K 전체            reference\HM450.hg38.mask.tsv.gz           Zhou 2017, github.com/zhou-lab/InfiniumAnnotationV1
탐침 위치             450K 전체            reference\HM450.hg38.manifest.tsv.gz       같은 저장소

출력                  크기                     파일                                  내용
LUAD 메틸화           탐침 400,772 × 414명      data\omics\luad_meth450_beta.h5       QC 후 β값 (float16), 탐침 ID, 환자 바코드
LUSC 메틸화           탐침 397,085 × 347명      data\omics\lusc_meth450_beta.h5       같음
```

450K 메틸화 자료에는 측정이 불안정한 탐침, 성별에 따라 값이 달라지는 성염색체 탐침, 결측이 많은 탐침이 섞여 있다. 이런 탐침이 남으면 메틸화 변동이 생물학이 아니라 측정 문제나 성별 구성을 반영할 수 있으므로, 분석 전에 제거하였다.

GDC 데이터 포털에서 받은 TCGA-LUAD·LUSC 원발 종양의 450K 메틸화 β값 파일(자료형 Methylation Beta Value, 플랫폼 Illumina Human Methylation 450, SeSAMe 처리; 환자당 1개, 2번)을 조직형별 탐침 × 환자 행렬로 합쳤다. 각 파일은 탐침 486,427개의 β값으로 이루어져 있다. 탐침 주석으로는 Zhou 등(Nucleic Acids Res 2017)이 hg38 기준으로 공개한 450K 마스크 파일과 탐침 위치 파일(InfiniumAnnotation, github.com/zhou-lab/InfiniumAnnotationV1)을 사용하였다. 다음 규칙을 차례로 적용하였다.
1. CpG 탐침만 사용하였다. 450K 탐침 ID 규칙에 따라 CpG 부위 탐침(cg)만 남기고, 비CpG 부위 탐침(ch)과 SNP 확인용 탐침(rs) 4,006개를 제외하였다.
2. 측정이 불안정한 탐침을 제외하였다. Zhou 등의 일반 마스크(M_general)에 해당하는 탐침 29,333개를 제외하였다. 이 마스크는 탐침 서열이 유전체의 여러 곳에 결합할 수 있는 탐침(교차 반응)과, 측정 위치에 흔한 SNP가 있어 유전형에 따라 값이 달라지는 탐침 등을 포함한다.
3. 성염색체 탐침을 제외하였다. Zhou 등의 탐침 위치 파일로 X·Y 염색체 탐침을 판정하여, 2단계에서 남은 10,845개를 제외하였다.
4. 결측이 많은 탐침을 제외하였다. 환자의 20% 이상에서 값이 없는 탐침을 제외하였다(LUAD 41,471개, LUSC 45,158개).
5. 남은 결측은 탐침 평균으로 대체하였다. 각 탐침의 결측을 그 탐침의 환자 평균 β값으로 채우고, float16으로 저장하였다.

```
                                   LUAD (414명)   LUSC (347명)
① 전체 탐침                          486,427        486,427
② CpG 탐침 (ch·rs 4,006개 제외)       482,421        482,421
③ 일반 마스크 제외 (−29,333)          453,088        453,088
④ 성염색체 제외 (−10,845)             442,243        442,243
⑤ 결측 20% 이상 제외                  400,772        397,085
   남은 비율                           82.4%          81.6%
   대체한 결측 비율                     0.53%          0.77%

④ 단계 탐침의 결측률 분포            LUAD           LUSC
   0%                                327,254        308,916
   0–1%                               38,064         39,403
   1–5%                               21,428         28,057
   5–20%                              14,026         20,709
   20–50% (제외)                        5,937          8,714
   50–100% (제외)                      35,534         36,444
```

최종 행렬은 LUAD 탐침 400,772개 × 414명, LUSC 탐침 397,085개 × 347명이었으며, 조직형별 h5 파일(luad_meth450_beta.h5, lusc_meth450_beta.h5)에 β값, 탐침 ID, 환자 바코드를 함께 저장하였다. 결측률은 두 갈래로 나뉘었다. 대부분의 탐침(LUAD 74.0%, LUSC 69.9%)은 결측이 전혀 없었던 반면, 약 3만 5천 개의 탐침은 환자 절반 이상에서 값이 없었다. 후자는 소수 환자의 측정 실패가 아니라 다수 환자에서 일관되게 빠진 탐침으로, 결측 20% 기준으로 걸러진 탐침의 대부분(LUAD 85.7%, LUSC 80.7%)을 차지하였다.

전체 탐침의 약 82%가 남았고, 남은 결측은 1% 미만이어서 평균 대체가 결과에 미치는 영향은 작다. 결측이 대부분 "거의 없음" 또는 "대부분 없음"으로 나뉘어, 결측 기준을 20%에서 10%나 30%로 바꾸어도 남는 탐침 수는 크게 달라지지 않는다. 다만 LUSC는 결측이 1–20%인 탐침이 LUAD보다 많아(48,766개 대 35,454개) 탐침이 3,687개 더 제외되었고 대체 비율도 높았으므로, LUSC 메틸화의 측정 품질이 다소 낮을 가능성을 염두에 두어야 한다.

분석에서 제외할 표본은 PanCanAtlas 표본 품질 표의 Do_not_use 열로 정하였다. 이 표는 PanCanAtlas 분석 과정에서 문제가 확인된 표본을 플랫폼(aliquot)별로 기록한 것으로, 원발 종양 표본 중 하나 이상이 Do_not_use로 표시된 환자를 제외 대상으로 표시하였다.

24명은 환자 단위의 임상 이력으로, 대부분 표본 채취 전 치료 이력 때문이었다(사전 치료 17명, 신보조 요법 1명, 사전 치료 주석 1명). 그 외에 다른 악성 종양(이전 1명, 동시 1명), 연구 등록 기준 미충족, 중복 등록, 품질 지표 변경이 각 1명이었다. 9명은 동결 조직이 아닌 FFPE 표본으로 측정되어 제외되었다. 나머지 12명은 특정 측정의 품질 문제로, Broad 분석 파이프라인의 QC를 통과하지 못한 aliquot(9명)과 RPPA 총 단백질 함량이 비정상적으로 낮은 aliquot(3명)이었다.

Do_not_use 환자는 이후 모든 분석에서 제외하며, 그 결과 분석 대상은 LUAD 452명, LUSC 453명이 된다(13번). 사전 치료나 다른 악성 종양이 있으면 종양의 분자 상태가 치료나 다른 질환의 영향을 받았을 수 있고, FFPE 표본은 동결 조직과 핵산 품질이 달라 다른 환자와 같은 기준으로 비교하기 어려우므로, 이들을 제외하는 것은 타당하다. 반면 특정 플랫폼의 QC 실패로 표시된 12명은 다른 층의 측정에는 문제가 없었을 수 있으나, 기준을 단순하게 유지하기 위해 환자 전체를 제외하였다. 이로 인한 표본 손실은 코호트의 1.3%로 작다.

두 조직형은 임상 특성이 뚜렷하게 달랐다. LUSC는 남성(74.8%)과 흡연자(비흡연 3.8%)가 대부분이고 흡연량도 많은 반면, LUAD는 여성이 절반 이상이고 비흡연자가 14.1%였다. 면역 아형도 LUAD는 C3(염증형)과 C2(IFN-γ 우세형), LUSC는 C1(상처 치유형)이 가장 많아, 조직형별로 분석해야 한다는 03의 결론과 일치한다. 모든 임상 정보를 PanCanAtlas의 표준화된 공개 표에서 가져왔으므로, 같은 파일 ID로 받으면 임상 표가 그대로 재현된다.
(면역 아형 출처: Thorsson V, Gibbs DL, Brown SD, et al. The Immune Landscape of Cancer. Immunity 2018;48(4):812–830.e14)

입력은 두 가지였다. 하나는 2번에서 고른 GDC Masked Somatic Mutation 파일을 가진 코호트 환자 목록(928명)이고, 다른 하나는 3번에서 이 파일들을 합쳐 비동의 변이 9종만 남긴 변이 표(변이 221,514개, 환자 922명)이다. 두 환자 수의 차이(6명)는 MAF 파일은 있으나 비동의 변이가 하나도 없는 환자로, 이들은 변이 표에 나타나지 않으므로 변이 상태는 변이 표가 아니라 MAF 보유 환자 목록을 기준으로 정하였다. 분석 대상 905명(5번) 중 MAF를 가진 환자는 LUAD 444명, LUSC 440명이었다.

단백질 서열을 바꾸는 비동의 변이(미스센스, 넌센스, 프레임시프트 삽입·결실, 인프레임 삽입·결실, 스플라이스 부위, 시작 코돈, 종결 소실)를 하나 이상 가진 경우를 그 유전자의 변이로 정의하였고, MAF를 가졌으나 해당 유전자에 비동의 변이가 없는 환자는 변이 없음으로 판정하였다.

LUAD에서는 KRAS(28.8%), KEAP1(17.6%), STK11(14.0%), EGFR(12.4%) 변이가, LUSC에서는 TP53(80.9%)과 NFE2L2(14.5%) 변이가 특징적이었다. NRF2 경로는 두 조직형 모두에서 약 5분의 1의 환자에게 변이가 있었으나, LUAD는 주로 KEAP1, LUSC는 주로 NFE2L2를 통해 변이되었다. LUAD에서 STK11 변이 환자의 절반(31/62명)은 KRAS 변이를, 3분의 1(20/62명)은 KEAP1 변이를 함께 가졌다.

환자별 비동의 변이 수(중앙값 LUAD 168.5개, LUSC 189.5개)는 Thorsson 등(Immunity 2018)이 PanCanAtlas MC3 변이 목록으로 계산한 공개 변이율(중앙값 5.36, 6.04 변이/Mb)과 거의 완전하게 같은 순위를 보였다(Spearman ρ = 0.99; 두 값을 모두 가진 LUAD 443명, LUSC 432명). 따라서 이후 분석의 변이 부담에는 엑솜 크기의 가정 없이 공개된 값을 쓸 수 있는 Thorsson의 변이율을 사용하였다.

변이 빈도가 TCGA 원 논문의 보고와 비슷하여, GDC 공개 MAF로도 주요 동인 변이의 상태가 재현된다. 두 조직형은 동인 구성이 뚜렷하게 달라, LUAD는 KRAS·STK11·KEAP1의 동시 변이가 흔하고 LUSC는 TP53 변이가 대부분의 환자에게 있다. 특히 LUSC에서 KRAS(1.4%), STK11(0.7%), EGFR(2.3%) 변이는 매우 드물어 이 유전자들로 LUSC 환자를 비교하는 분석은 통계적 검정력이 낮으므로, 조직형마다 충분한 빈도를 가진 유전자로 해석을 한정해야 한다. 서로 다른 변이 호출 결과(GDC 공개 MAF와 PanCanAtlas MC3)에서 얻은 변이 부담이 같은 순위를 주므로, 공개 변이율을 써도 정보 손실 없이 재현성을 높일 수 있다.

종양 상태의 미세환경 축은 RNA 전체가 아니라 미세환경 구성 요소를 따로 재는 시그니처로 정의한다(03 변동 진단 4절에서 RNA 전체에 종양 세포와 미세환경 신호가 섞여 있음을 확인). 이를 위해 Bagaev 등(Cancer Cell 2021)의 29개 기능 유전자 시그니처(MFP)를 계산하였다. MFP는 면역세포, 기질, 혈관, 증식을 각각 점수화하여 ESTIMATE(면역·기질 두 점수)보다 해상도가 높고, 이로 정의한 아형이 여러 암종에서 면역항암제 반응과 연관되며, 시그니처와 원 논문 점수가 공개되어 계산을 검증할 수 있다. 이 점수는 MFP 아형 분류(9절), 층 선택의 표적(02 분자 층 선택), 다층 요인 분석의 미세환경 층(04 피처 확정)에 쓰인다.

RNA 발현은 log2(TPM + 1)로 변환하고, 원 논문의 방식대로 단백질 코딩 유전자와 T세포 수용체·면역글로불린 불변 부위 유전자(TR_C, IG_C)만 남겼다. 같은 이름의 유전자가 여럿이면 평균 발현이 가장 높은 것 하나를 썼으며, 그 결과 19,958개 유전자 × 905명의 발현 행렬을 얻었다. 각 시그니처 점수는 원 논문의 단일 표본 유전자 집합 농축 분석(ssGSEA) 식으로 계산한 뒤, 조직형마다 중앙값 표준화(중앙값을 빼고 평균 절대 편차로 나눔)를 하였다. 출력 점수는 0이 그 조직형의 중앙값이고, 양수일수록 그 미세환경 요소가 조직형 안에서 상대적으로 많다는 뜻이다. 시그니처를 이루는 유전자(시그니처당 5–19개)는 29개 시그니처 모두에서 발현 행렬에 빠짐없이 있었다.

```
원 논문 점수와 비교 (두 자료에 모두 있는 893명, Spearman ρ)
  29개 시그니처 중앙값 0.991, 범위 0.885–0.998
  ρ < 0.95인 시그니처: Th2_signature 0.885 (유전자 5개), Antitumor_cytokines 0.937 (6개)
  ρ ≥ 0.99인 시그니처: 18개 (B_cells 0.998, T_cells 0.997, Checkpoint_inhibition 0.997 등)
표준화 확인: 29개 시그니처 모두 조직형별 중앙값 0.000
```

원 논문의 범암종 코호트에 포함된 893명에서, 계산한 점수는 원 논문 점수와 시그니처 중앙값 ρ = 0.991로 일치하였다. 가장 낮은 두 시그니처(Th2 0.885, 항종양 사이토카인 0.937)는 유전자가 5–6개로 가장 적은 시그니처였다. 표준화 후 모든 시그니처의 조직형별 중앙값은 0이었다. 출력 점수는 8절에서 MFP_ 이름을 붙여 면역 점수 표(data\annot\immune_scores.csv)에 함께 저장된다.

29개 시그니처 모두 원 논문 점수와 강하게 일치하여, MFP 계산이 원 논문의 방식대로 재현되었다. 유전자가 적은 시그니처에서 일치도가 다소 낮은 것은, 표준화에 쓰인 환자 집단이 원 논문(범암종 전체)과 우리(폐암 코호트)에서 달라 유전자 순위의 작은 차이가 적은 유전자 수에서 더 크게 반영되기 때문으로 보인다. 따라서 이 점수를 미세환경 축의 기준으로 사용하되, Th2와 항종양 사이토카인처럼 유전자가 적은 시그니처는 해석할 때 상대적으로 불안정할 수 있음을 염두에 둔다. 또한 점수를 조직형별로 표준화했으므로 LUAD와 LUSC 사이의 점수 크기는 직접 비교할 수 없고, 이 점수는 모두 RNA에서 계산되므로 RNA 축을 해석할 때는 RNA가 아닌 자료로 잰 지표로 함께 확인해야 한다(03 변동 진단).



### 8. 면역 점수

미세환경을 한 가지 방법으로만 재면 그 방법의 특성(유전자 목록, 계산 방식)에 결과가 좌우될 수 있다. 같은 세포나 성분을 서로 다른 방법으로 재 두면, 이후 해석이 특정 방법에 의존하는지 확인할 수 있다. 이를 위해 MFP(7절)에 더해 면역·기질의 전체 양을 재는 ESTIMATE(Yoshihara et al., Nat Commun 2013), 세포 유형별 양을 재는 MCP-counter(Becht et al., Genome Biol 2016), 면역세포 비율을 백혈구 양으로 환산한 CIBERSORT 절대값(Thorsson et al., Immunity 2018), 폐암에서 면역항암제 반응과 연관된 폐 패널을 함께 계산하였다. 이 점수들은 층 선택의 표적(02 분자 층 선택), 변동 진단의 공변량(03 변동 진단), 다층 요인 분석의 미세환경 층(04 피처 확정)에 쓰인다.

입력과 출력은 다음과 같다.

```

발현 행렬 xa           59,427 유전자 × 905명    모든 유전자 종류, 조직형별 z 점수            GDC STAR - Counts (3절)

점수는 묶음마다 다음과 같이 계산하였다. ESTIMATE는 면역·기질 유전자 집합의 단일 표본 농축 점수를 원 논문의 순위 기반 식으로 계산하였다. MCP-counter는 세포 유형별 마커 유전자의 평균 발현(log2 TPM)이다. CIBERSORT 절대값은 Thorsson 등이 공개한 22개 면역세포의 상대 비율에 백혈구 비율(Leukocyte Fraction)을 곱해, 조직 안 면역세포 양으로 환산하였다. 폐 패널은 조직형마다 유전자를 z 점수로 바꾼 뒤 평균하였으며, 세포독성 활성(CYT; GZMA, PRF1), T세포 염증 유전자 발현 프로파일(GEP18), 삼차 림프 구조 케모카인(TLS12), 면역 프로테아좀, 폐암 호중구(LuCA), 형질세포(Patil), 삼차 림프 구조 유전자(TLS8; Cabrita et al., Nature 2020의 9개 중 Y 염색체 유전자 EIF1AY 제외)로 구성된다.

```

같은 RNA에서 마커 유전자로 계산한 점수끼리(MCP-counter 대 MFP의 T세포·섬유모세포)는 ρ = 0.91–0.94로 매우 강하게 일치하였다. RNA로 계산한 ESTIMATE와 메틸화로 추정한 Thorsson의 백혈구·기질 비율은 서로 다른 자료임에도 ρ = 0.60–0.78로 일치하였다. 디컨볼루션 기반의 CIBERSORT와 마커 기반 점수의 일치는 LUAD(0.70–0.75)에서 LUSC(0.51–0.58)보다 높았고, 세포독성 점수도 LUAD(0.87)가 LUSC(0.66)보다 높았다.

같은 대상을 재는 서로 다른 방법의 점수가 일치하여, 이후 미세환경 해석이 특정 방법의 유전자 목록이나 계산 방식에 크게 좌우되지 않는다. 특히 RNA 기반 ESTIMATE와 메틸화 기반 백혈구·기질 비율의 일치는 서로 다른 자료 사이의 일치이므로, 미세환경 점수가 RNA 측정의 특성만을 반영하지 않는다는 근거가 된다. 다만 세포 유형을 세분할수록(CD8 T세포, 형질세포) 방법 간 일치가 낮아지고, 그 경향은 LUSC에서 더 뚜렷하였다. 이는 LUSC에서 세포 유형 간 구분이 RNA만으로는 덜 분명함을 시사하므로, 세부 면역세포 점수는 LUSC에서 더 조심스럽게 해석해야 한다. CIBERSORT 절대값은 48명이 결측이어서, 이 점수를 쓰는 분석에서는 표본이 약 5% 줄어든다. 또한 ESTIMATE, MCP-counter, 폐 패널, MFP는 모두 같은 RNA에서 계산되므로, RNA 축을 해석할 때는 RNA가 아닌 자료로 잰 지표(순도, 메틸화 기반 비율, 병리 판독)로 함께 확인해야 한다(03 변동 진단).

### 9. MFP 아형

Bagaev 등(Cancer Cell 2021)은 29개 MFP 점수로 종양 미세환경을 네 가지 아형으로 나누었다. 면역이 풍부하고 기질이 적은 면역 풍부형(IE), 면역과 섬유화가 함께 많은 면역 풍부·섬유화형(IE/F), 기질이 많고 면역이 적은 섬유화형(F), 면역과 기질이 모두 적은 면역 결핍형(D)이다. 이 아형은 여러 암종에서 면역항암제 반응과 연관되어, 층 선택의 범주 표적(02 분자 층 선택)이자 이후 종양 상태를 해석하는 기준으로 쓴다.

입력과 출력은 다음과 같다.

```

분류는 원 논문이 공개한 범암종 코호트를 참조로 한 최근접 이웃 분류(KNN)로 하였다. 참조에서 폐암(LUAD, LUSC)을 제외한 23개 암종 7,031명을 학습 집단으로 썼다. 우리 폐암 환자는 대부분 원 논문의 참조에도 포함되어 있으므로, 폐암을 참조에 남기면 자기 자신의 라벨로 분류하게 되어 일치도가 부풀려지기 때문이다. 학습 집단의 아형은 IE 1,678명, IE/F 1,093명, F 1,487명, D 2,773명이었다. 특징은 29개 MFP 점수로, 학습 집단과 우리 점수 모두 극단값의 영향을 줄이기 위해 −2에서 2 사이로 잘랐다. 분류기는 유클리드 거리로 가장 가까운 35명의 학습 환자를 찾아 다수결로 아형을 정하는 KNN(scikit-learn KNeighborsClassifier, k = 35, 같은 가중치)으로, 후보 0의 13번에서 원 논문의 분류 방식에 맞춰 정한 설정을 그대로 썼다. 분류의 정확도는 우리 환자 중 원 논문 라벨이 있는 893명에서 원 라벨과 비교하여 평가하였고, 일치율과 함께 우연 일치를 보정한 Cohen 카파를 계산하였다.

폐암을 학습에 쓰지 않고도 원 라벨과 85%가 일치하고 카파가 0.79로 높아, 원 논문의 분류가 독립적으로 재현되었다. 불일치한 환자는 이웃 투표가 두 아형으로 갈려 있어(다수 아형 비율 약 0.5) 분류 경계에 놓인 환자였다. 혼동도 면역 양이나 섬유화 정도가 한 단계 다른 이웃 아형 사이(IE/F와 IE, F와 D)에서 주로 일어났다. 이는 미세환경 아형이 뚜렷하게 나뉜 범주라기보다 면역과 섬유화라는 연속적인 축 위의 구간에 가깝다는 뜻으로, 종양 상태를 이산 아형보다 연속적인 축으로 정의하는 것이 적절하다는 02 분자 층 선택과 03 변동 진단의 결론과 일치한다. 따라서 MFP 아형은 상태를 해석하는 참고 범주로 쓰되, 경계 환자가 약 15% 있음을 고려해 아형 자체보다 7절의 연속 점수를 주 지표로 사용한다.

### 10. RPPA 정리

RPPA(역상 단백질 배열)는 항체 패널이 측정 시기에 따라 달라, 일부 항체는 측정되지 않은 환자가 많다. 결측이 많은 항체를 그대로 쓰면 항체마다 분석 환자가 달라지고 대체값이 결과를 좌우할 수 있으므로, 대부분의 환자에서 측정된 항체만 남겼다. 정리한 RPPA는 층 선택의 단백질 층(02 분자 층 선택)과 이후 층 간 검증, wsi2rppa의 단백질 정답으로 쓰인다.

입력과 출력은 다음과 같다.

```
입력                크기                  파일                                    최초 출처

                                                                                 (protein_expression 열)

출력                크기                  파일                                    내용

```
분석 대상 중 RPPA가 있는 600명(LUAD 311명, LUSC 289명)에서, 항체마다 조직형별 결측률을 구하고 두 조직형 중 큰 값이 10% 이하인 항체만 남겼다.

### 11. MeTIL과 MeTIL-2

메틸화에서 T세포 침윤을 재는 지표가 필요하다. MeTIL(Jeschke et al., J Clin Invest 2017)은 T세포에서 특이하게 메틸화가 낮은 탐침 5개로 만든 점수로, 유방암에서 개발되어 폐암을 포함한 여러 암종에 적용되었다. 다만 다른 암종에서 개발된 지표이므로, 폐암 자료에서도 각 탐침이 실제로 면역세포의 양을 따르는지 먼저 확인할 필요가 있다. 특히 폐선암에는 종양 세포가 CpG 섬을 넓게 메틸화하는 CIMP 아형이 있어(TCGA, Nature 2014), CpG 섬에 위치한 탐침은 면역세포와 무관하게 값이 달라질 수 있다. 그래서 원래 MeTIL을 계산한 뒤(11-1), 탐침마다 종양의 CpG 섬 메틸화 수준과 면역 점수 중 무엇을 따르는지 확인하고(11-2), 그 결과에 따라 대안 점수를 만들어 독립 지표로 검증하였다(11-3).

```

원래 MeTIL은 Jeschke 등의 고정 파라미터로 계산하였다. 탐침 i의 β값에서 기준값(c1)을 빼고 척도(s1)로 나눈 뒤 가중치(v1)를 곱해 다섯 탐침을 합하였으며, 다섯 탐침이 모두 있는 환자만 계산하였다. 분석 대상 중 메틸화가 있는 736명(LUAD 398명, LUSC 338명) 전원에서 계산되었다.

MeTIL의 5개 탐침은 서로 다른 신호를 따랐다. PTPRCAP과 KLHL6 탐침은 두 조직형 모두에서 면역 점수(ρ = −0.71 ~ −0.77) 및 순도(ρ = 0.68 ~ 0.72)와 강하게 상관하였고, CIMP 지수와는 거의 무관하였다. 반면 INA 탐침은 두 조직형 모두에서(ρ = 0.57, 0.41), RASSF1 탐침은 LUSC에서(ρ = 0.44) 면역과 거의 무관하게 CIMP 지수를 따랐다. SEMA3B 탐침은 두 신호 모두와 약하게만 상관하였다. MeTIL을 CIMP 지수와 면역 점수로 회귀하면 두 변수가 함께 MeTIL 변동의 절반 남짓을 설명하였고(R² = 0.54, 0.51), 면역의 계수가 더 컸으나 CIMP의 계수도 상당하였다(LUAD −0.37, LUSC −0.43).

이에 면역을 따른 두 탐침(PTPRCAP, KLHL6)만으로 MeTIL-2를 정의하였다. 두 탐침의 M값을 각각 표준화하여 평균한 뒤 부호를 뒤집어, 원래 MeTIL처럼 값이 클수록 T세포가 많도록 하였다. 두 탐침은 ESTIMATE 면역 점수와의 상관을 보고 골랐으므로, 검증에는 탐침 선택에 쓰지 않은 독립 지표만 사용하였다. RNA 기반의 MCP-counter T세포 점수와 CIBERSORT T세포 절대값의 합, MeTIL과 다른 백혈구 특이 탐침으로 추정한 Thorsson의 백혈구 비율, H&E 슬라이드 이미지에서 측정한 TIL 영역 비율(Saltz et al., Cell Rep 2018)이다.

```

MeTIL-2는 네 가지 독립 TIL 지표 모두에서 원래 MeTIL보다 강하게 상관하였다(LUAD +0.04 ~ +0.18, LUSC +0.11 ~ +0.19). 메틸화나 RNA와 무관하게 이미지에서 측정한 TIL 영역 비율과의 상관도 MeTIL-2에서 높았으며, 개선 폭은 LUSC(0.23 → 0.34)에서 컸다. 원래 MeTIL은 CIMP 지수와 음의 상관을 보였으나(LUAD −0.22, LUSC −0.44), MeTIL-2에서는 그 상관이 거의 사라졌다(0.10, −0.13).

이 코호트에서 원래 MeTIL은 T세포 양과 함께 종양의 CIMP를 반영하였다. CIMP가 높은 종양에서는 일부 탐침의 메틸화가 올라가 MeTIL이 낮아지므로, T세포가 실제보다 적게 추정된다. 이 영향은 LUSC에서 더 컸다. 면역 표지 탐침 두 개로 만든 MeTIL-2는 CIMP의 영향을 거의 받지 않으면서 서로 다른 자료로 잰 TIL 지표와 더 잘 일치하였으므로, 이후 분석에서는 MeTIL-2를 메틸화 기반 TIL 지표로 사용한다. 다만 Thorsson의 백혈구 비율도 메틸화로 추정한 값이어서 이 지표와의 높은 상관(0.91–0.93)에는 같은 측정 방식에서 오는 공통 변동이 일부 포함되었을 수 있고, TIL 영역 비율과의 상관이 모든 점수에서 낮은 것(0.23–0.35)은 이 값이 분자 분석에 쓰인 동결 조직이 아니라 별도의 진단용 슬라이드에서 측정되었기 때문으로 보인다. 탐침의 일부가 종양 고유의 메틸화를 따르는 문제는 CIMP가 있는 다른 암종에서도 생길 수 있으므로, 다른 암종에서 개발된 메틸화 기반 면역 지표를 쓸 때는 탐침별로 신호를 확인할 필요가 있다.

### 13. 현황

이후 단계는 분석마다 필요한 자료가 다르므로, 분석 대상 안에서 자료별로 몇 명이 남는지와 분석에 쓰는 층 조합마다 공통 환자가 몇 명인지를 미리 정리하였다. 이 표가 이후 각 단계의 표본 수를 정하는 기준이 된다.

```
입력                  파일                              최초 출처

```

분석 대상은 코호트(진단용 슬라이드와 원발 종양 RNA를 모두 가진 950명) 중 Do_not_use를 제외한 LUAD 452명, LUSC 453명(총 905명)이다.

RNA와 RNA에서 계산한 점수(MFP, 면역 점수)는 분석 대상 전원이 가졌고, miRNA, 체세포 변이, 복제수 팔 판정, IHC 순도도 97% 이상이 가졌다. 메틸화는 LUAD 88.1%, LUSC 74.6%, RPPA는 68.8%, 63.8%만 가졌으며, 원 논문의 CIMP와 발현 아형 라벨은 원 논문에 포함된 일부 환자에게만 있었다.

실제 분석은 필요한 층을 모두 가진 환자에서만 수행하므로, 분석마다 대상 환자 수가 다르다.

```

메틸화를 포함하는 분석은 LUAD의 약 85%, LUSC의 약 73%에서 수행되며, 여기에 복제수와 변이, 생존과 공변량을 더해도 환자가 크게 줄지 않는다. 메틸화가 주 층인 다층 요인 분석(04 피처 확정)과 그 결과를 쓰는 생존 분석은 LUAD 375–387명, LUSC 323–334명에서 이루어진다. 반면 여섯 층을 모두 요구하는 층 선택 분석(02 분자 층 선택)은 RPPA와 메틸화의 결측이 겹쳐 분석 대상의 약 절반(LUAD 261명, LUSC 224명)으로 줄어든다.

이후 단계의 표본 수는 대부분 메틸화 보유 여부로 정해지며, 특히 LUSC는 메틸화 결측 때문에 분석 대상의 약 4분의 1이 다층 분석에서 빠진다. 메틸화가 없는 환자가 무작위로 빠진 것이 아니라면 결과가 치우칠 수 있으므로, 메틸화 보유 환자와 그렇지 않은 환자의 임상 특성(병기, 생존, 흡연)이 다른지 이후 단계에서 확인할 필요가 있다. 층 선택 분석은 공통 환자가 약 절반으로 줄어드므로, 그 결과는 이 부분집합에 대한 것임을 함께 밝힌다.
