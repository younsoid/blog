# 데이터 준비 (01)

#2026-11-02

---

### 1. GDC 파일 목록과 코호트

GDC API로 TCGA-LUAD·LUSC의 파일 목록(RNA, miRNA, 변이, RPPA, 450K 메틸화, 진단용 슬라이드)을 받아 환자별 보유 자료를 정리하고 코호트를 정했다.

```
원발 종양 자료가 있는 환자: LUAD 571, LUSC 504
코호트 (DX 슬라이드 + RNA): LUAD 474, LUSC 476
```

병리 이미지 분석과 오믹스 분석이 같은 환자에서 이뤄지도록 코호트를 DX 슬라이드와 RNA를 모두 가진 환자로 정하였다. RNA는 있으나 DX 슬라이드가 없는 환자(LUAD 43명, LUSC 25명)는 제외되었다.

### 2. 환자당 층별 파일 선택과 다운로드

한 환자에게 같은 층의 파일이 여러 개 있을 수 있으므로(재측정, 여러 aliquot), 환자당 원발 종양 파일 하나만 고르는 규칙이 필요하다. GDC에서 받고 md5로 확인하였다.

```
         LUAD  LUSC
RNA       474   476
miRNA     467   460
변이      465   463
메틸화    414   347
RPPA      328   304
```

RNA·miRNA·변이는 코호트의 거의 전원이 보유한 반면, 메틸화(LUAD 87%, LUSC 73%)와 RPPA(LUAD 69%, LUSC 64%)는 일부가 빠져 있다. 이 차이 때문에 층 간 비교(02)는 공통 환자에서 수행해야 한다.

### 3. 오믹스 표

환자별로 흩어진 원자료 파일을 분석에 쓸 수 있는 행렬로 합친다. RNA는 TPM, 변이는 비동의 변이 9종, RPPA는 항체 × 환자, miRNA는 log2 RPM 행렬로 정리하였다.

```
환자 수: RNA 950, miRNA 927, 변이 928, RPPA 632
```

이후 단계는 원자료 대신 이 행렬을 읽는다. 

### 3-1. 메틸화 β 행렬과 QC

450K 메틸화에는 측정이 불안정한 탐침(SNP 인접, 교차 반응), 성별에 따라 값이 달라지는 성염색체 탐침, 결측이 많은 탐침이 섞여 있다. 이런 탐침이 남으면 메틸화 변동이 생물학이 아니라 측정 문제나 성별을 반영할 수 있으므로, 
~ 규칙으로 제거하였다.

```
         환자   탐침 486,427 → cg·마스크·성염색체 제외 → 결측 20% 이상 제외   결측 대체
LUAD     414                    442,243               400,772                0.53%
LUSC     347                    442,243               397,085                0.77%
```

전체 탐침의 약 82%가 남았고 남은 결측은 1% 미만이어서, 평균 대체가 결과에 미치는 영향은 작다.

### 4. 임상

생존, 병기, 나이, 흡연, 순도 같은 임상·병리 정보와 분석에서 제외할 표본을 한 표로 모아야 한다. TCGA-CDR, PanCanAtlas 임상·ABSOLUTE·표본 품질 표, Thorsson 면역 표를 합쳤다.

```
임상 표 950명 × 23열
Do_not_use: LUAD 22명, LUSC 23명
```

Do_not_use 표본은 PanCanAtlas가 품질 문제로 분석 제외를 권고한 것이므로 이후 모든 분석에서 제외한다. 그 결과 분석 대상은 LUAD 452명, LUSC 453명이 된다(13번).

### 5. 환자별 보유 표

왜 했나. 분석마다 필요한 자료를 가진 환자가 다르므로, 환자별 보유 자료를 한 표로 정리하여 이후 단계가 같은 기준으로 환자를 고르도록 하였다.

결과.

```
            LUAD  LUSC
DX · RNA     474   476
변이         465   463
miRNA        467   460
메틸화       414   347
RPPA         328   304
복제수 팔    455   457
생존         465   470
공변량       447   463
Do_not_use    22    23
```

시사점. 생존 정보는 거의 전원에게 있어 예후 분석의 표본 손실이 작다. 반면 LUAD에서는 나이·병기가 빠진 환자가 27명이어서, 공변량 보정 모형에서는 그만큼 표본이 줄어든다.

### 6. 변이 상태·TMB

왜 했나. 폐암 주요 동인 유전자의 변이는 종양 상태를 해석하는 기준이 된다(02의 표적, 이후 상태 특성). 비동의 변이로 유전자별 변이 여부를 정하고, STK11·KEAP1 절단 변이와 EGFR 활성화 변이를 따로 표시하였다.

결과.

```
         TP53  KRAS  EGFR  STK11  KEAP1  NFE2L2   (%)
LUAD     48.2  28.8  12.4   14.0   17.6     2.3
LUSC     80.9   1.4   2.3    0.7   10.5    14.5
```

시사점. 변이 빈도가 TCGA 원 보고와 거의 같아, GDC 공개 MAF로도 변이 상태가 정확하게 재현된다. LUAD는 KRAS·STK11·KEAP1, LUSC는 TP53·NFE2L2 변이가 특징적이어서 두 조직형의 동인 구성이 다르다. 이 표의 TMB는 엑솜 크기(38 Mb)의 근거 문제로 이후 분석에 사용하지 않으며, 변이율은 Thorsson의 공개 지표를 사용한다.

### 7. MFP 29 시그니처

미세환경 층(04)과 MFP 아형(9번)의 기초가 되는 점수이다. Bagaev 2021의 29개 시그니처를 원 논문과 같은 방식(ssGSEA, 암종별 중앙값 표준화)으로 계산하였다.

```
905명 × 29개 시그니처
원 논문 범암종 점수와 Spearman 상관 중앙값 0.991
```

원 논문이 공개한 점수와 거의 같아 계산이 정확히 재현되었다. 따라서 이 점수를 미세환경 축의 기준으로 사용할 수 있다.

### 8. 면역 점수

미세환경을 한 가지 방법으로만 재면 그 방법의 특성에 결과가 좌우될 수 있다. ESTIMATE(면역·기질), MCP-counter(세포 유형), CIBERSORT 절대값(Thorsson 비율 × 백혈구 비율), 폐 패널(CYT, GEP18, TLS12, 면역 프로테아좀, 호중구, 형질세포, TLS8)을 함께 계산하였다.

```
905명 × 71개 점수
```

이후 분석의 미세환경 관련 데이터가 이 표에서 나온다. (02의 표적, 03의 공변량, 04의 미세환경 층) 다만 이 점수들은 모두 RNA에서 계산되므로, RNA 축을 해석할 때는 RNA가 아닌 자료로 잰 지표(순도, 메틸화 기반 비율, 병리 판독)로 함께 확인해야 한다(03).

### 9. MFP 아형

Bagaev 2021의 네 가지 미세환경 아형(IE, IE/F, F, D)은 02의 범주 표적이자 이후 상태를 해석하는 기준이다. 원 논문의 범암종 참조에서 폐암을 제외한 환자로 분류기를 학습하여 폐암 환자를 분류하였다.

```
원 논문 라벨과 일치 84.9% (893명)
```

폐암을 학습에 쓰지 않고도 원 라벨과 85%가 일치하여, 원 논문의 분류 방식이 잘 재현되었다. 불일치한 15%는 아형 경계에 있는 환자로, 미세환경 아형을 이산 범주보다 연속적인 축으로 보아야 한다는 03의 결론과 일치한다.

### 10. RPPA 정리

RPPA는 항체 패널이 측정 시기에 따라 달라, 일부 항체는 측정되지 않은 환자가 많다. 결측이 많은 항체를 그대로 쓰면 항체마다 분석 환자가 달라지므로, 두 조직형 모두에서 결측 10% 이하인 항체만 남겼다.

```
분석 대상 중 RPPA 보유: LUAD 311명, LUSC 289명
항체 468 → 455개 (결측 10% 이하)
남긴 항체: 결측 최대 2.8%, 인산화 항체 91개
제외 13개 (모두 결측 LUAD 37.6%, LUSC 42.2%):
  AXL, BRCA2, CASPASE9, CTLA4, E2F1, EZH2, GATA6, NAPSINA, NRF2, P63, PDCD1, RET_pY905, TTF1
```

항체의 결측률이 3% 미만과 약 40%의 두 갈래로만 나뉘어, 기준값을 바꾸어도 남는 항체는 같다. 13개가 같은 환자들에서 함께 빠진 것은 패널에 나중에 추가된 항체이기 때문으로 보인다. EGFR·LKB1·AMPK와 그 인산화형, PD-L1, p53, mTOR·MAPK 경로 단백질은 결측 없이 남아 단백질 층을 층 간 비교(02 분자 층 선택)와 검증에 쓸 수 있다. 반면 NRF2, TTF-1, Napsin A, p63은 제외되었으므로 wsi2rppa 단계에서 측정된 환자(약 60%)로 따로 다룬다. 항체–유전자 대응은 이후 층 간 검증에서 MD Anderson의 공식 항체 주석(TCPA)으로 수행한다.

### 11. MeTIL과 MeTIL-2

### 11-1. 원래 MeTIL

메틸화에서 T세포 침윤을 재는 지표가 필요하다. 유방암에서 개발되어 여러 암종에 적용된 MeTIL(Jeschke et al., J Clin Invest 2017)을, T세포 특이 저메틸화 탐침 5개와 원 논문의 고정 파라미터로 계산하였다.

```
736명 (분석 대상 중 LUAD 398명, LUSC 338명)
```

메틸화를 가진 분석 대상 전원에게 점수가 계산되었다. 다른 암종에서 개발된 지표이므로, 폐암 자료에서도 각 탐침이 면역세포의 양을 따르는지 확인한다(11-2).

### 11-2. CIMP 오염 진단

폐선암에는 종양 세포가 CpG 섬을 넓게 메틸화하는 CIMP 아형이 있어, CpG 섬에 위치한 탐침은 면역세포와 무관하게 값이 달라질 수 있다. 탐침마다 CIMP 지수(프로모터 근처 변동 상위 탐침 중 CpG 섬 탐침의 평균 M값)와 ESTIMATE 면역 점수 중 무엇을 따르는지 확인하고, MeTIL을 두 변수로 회귀하였다.

```
탐침별 Spearman ρ (LUAD / LUSC)   CIMP 지수       ESTIMATE 면역
PTPRCAP                           −0.15 / 0.04    −0.77 / −0.71    ← 면역
KLHL6                             −0.07 / 0.20    −0.72 / −0.72    ← 면역
INA                                0.57 / 0.41    −0.18 / 0.10     ← CIMP
RASSF1                             0.09 / 0.44    −0.19 / −0.03    ← CIMP (LUSC)
SEMA3B                             0.17 / 0.21    −0.37 / −0.26    ← 둘 다 약함
MeTIL 회귀 (표준화 β)              CIMP −0.37 / −0.43, 면역 0.71 / 0.55, R² 0.54 / 0.51
```

이 코호트에서 MeTIL은 T세포 양과 함께 종양의 CIMP를 반영하였다. CIMP가 높은 종양에서는 T세포가 실제보다 적게 추정되며, 이 영향은 LUSC에서 더 크다.

### 11-3. MeTIL-2 정의와 검증

면역을 따른 두 탐침(PTPRCAP, KLHL6)만으로 MeTIL-2를 정의하였다(표준화 M값 평균의 부호를 뒤집어, 클수록 T세포가 많음). 탐침 선택에 ESTIMATE를 썼으므로, 검증은 ESTIMATE가 아닌 독립 TIL 지표로 하였다.

```
Spearman ρ (MeTIL → MeTIL-2)      LUAD            LUSC
MCP T세포 (RNA)                   0.59 → 0.71     0.45 → 0.58
CIBERSORT T세포 합 (RNA)           0.69 → 0.87     0.66 → 0.82
백혈구 비율 (메틸화)                0.77 → 0.93     0.72 → 0.91
TIL 영역 비율 (H&E 이미지)          0.31 → 0.35     0.23 → 0.34
CIMP 지수                          −0.22 → 0.10    −0.44 → −0.13
```

MeTIL-2는 CIMP와의 상관이 거의 사라졌고, 네 가지 독립 지표 모두에서 원래 MeTIL보다 강하게 상관하였다. 이후 분석에서는 MeTIL-2를 메틸화 기반 TIL 지표로 사용한다(data\annot\metil.csv에 MeTIL, CIMP 지수와 함께 저장).

### 12. 공개 라벨

결과를 독립적으로 검증하려면 우리가 직접 정의하지 않은 공개 지표가 필요하다. 이수성 점수(Taylor 2018), 순도 5종(Aran 2015), LUAD CIMP·발현 아형(TCGA 2014), LUSC 발현 아형(Thorsson 2018)을 모았다.

```
                  LUAD  LUSC
이수성 점수        440   449
순도 IHC           447   448
순도 ABSOLUTE      303   296
CIMP 라벨          155     0
발현 아형 라벨     195   157
```

병리의가 판독한 IHC 순도가 거의 전원에게 있어, RNA와 완전히 독립적인 조직 구성 지표로 사용할 수 있다. 원 논문의 CIMP와 발현 아형 라벨은 일부 환자에게만 있으므로, 03에서는 CIMP 축의 검증에, 04에서는 전원 분류(Wilkerson 중심값)의 정확도 확인에 사용한다.

### 13. 현황

왜 했나. 이후 단계가 실제로 사용하는 분석 대상(코호트 중 Do_not_use 제외) 안에서 자료별 환자 수를 확인하기 위해 정리하였다.

결과.

```
분석 대상: LUAD 452, LUSC 453
            LUAD  LUSC
RNA·DX       452   453
변이         444   440
miRNA        446   439
메틸화       398   338
복제수 팔    440   449
RPPA         311   289
```

시사점. 이후 모든 분석은 이 905명을 기준으로 한다.
