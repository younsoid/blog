### 

코드 순서

00_env_check.ipynb — 환경 세 개 점검과 공통 설정
- 목적: 세 환경(1.0용, 2.5용, HoVer-Net용)이 각각 필요한 패키지를 import할 수 있는지, GPU가 보이는지 확인하고 config.yaml을 만듭니다.
- 분석 환경 점검: Python 3.14에서 scikit-learn, lifelines, umap(numba 의존), statsmodels가 설치되는지 확인하고, 안 되면 분석 전용 3.12 환경을 만드는 판단을 여기서 내립니다.
- HoVer-Net 환경: TIAToolbox용 별도 환경(Python 3.10~3.11)에서 PanNuke HoVer-Net 가중치 다운로드와 작은 타일 하나 추론까지 확인합니다.
- 보안: Hugging Face 토큰은 노트북에 쓰지 않고 hf auth login 또는 환경 변수로만 사용합니다. 이전 BRCA 노트북에서 정리하셨던 토큰 폐기 건을 여기서 마무리합니다.
- 출력: config.yaml, 환경별 패키지 버전 기록(logs/env_versions.json).

01_cohort_manifest.ipynb — 코호트 장부와 처리 우선순위
- GDC에서 TCGA-LUAD, TCGA-LUSC의 DX 슬라이드 목록과 case 정보를 조회합니다. 기존 data/의 mmc2, 메틸화 파일 목록, CDR 등이 있으면 환자 ID 기준으로 붙여 "어떤 환자가 어떤 데이터를 갖고 있는지" 표를 만듭니다.
- 바코드에서 환자 ID, TSS(기관), DX 번호를 파싱합니다. 기관별 환자 수를 보고 site-aware split이 가능한 구조인지 미리 확인합니다.
- 처리 우선순위 열을 만듭니다: 1순위 LUAD 중 Thorsson + 메틸화 + 생존이 모두 있는 환자의 DX1, 2순위 나머지 LUAD DX1, 3순위 LUSC 같은 순서, 4순위 추가 DX 슬라이드.
- 디스크·시간 추정: 총 용량, 우선순위 그룹별 용량을 계산합니다.
- 출력: manifest/slides.csv, manifest/patients.csv(데이터 보유 여부 열 포함).

02_pilot_pipeline.ipynb — 슬라이드 2~3장으로 파이프라인 확정
- 목적: 배치 스크립트에 넣을 모든 처리를 눈으로 확인하며 파라미터를 결정합니다. 기존 01~03을 하나로 합친 개선판입니다.
- MPP 읽기: openslide 속성에서 MPP·AppMag를 읽고, MPP가 없으면 AppMag로 추정(40×→0.25, 20×→0.5)하며 그 사실을 플래그로 남깁니다.
- 조직 mask 개선: 기존 밝기·채도 규칙에 펜 자국 제거, 작은 구멍·잡음을 지우는 형태학적 정리를 더하고, 썸네일 위에 겹쳐 확인합니다.
- MPP 정규화 타일링: 목표 0.5 µm/px에서 256px가 되도록 원본에서 읽을 크기를 계산(예: 0.25 MPP면 512px를 읽어 256으로 축소)하고, 효율을 위해 가능한 경우 더 낮은 레벨에서 읽습니다. 20×와 40× 슬라이드에서 같은 크기의 조직이 잘리는지 나란히 비교합니다.
- 품질 필터와 Macenko, 1.0 임베딩: 기존 로직 유지, 실패 타일 수 기록.
- HoVer-Net 영역 샘플링 설계: 영역 크기(예: 0.25 MPP에서 2048×2048px, 약 0.26 mm²)와 슬라이드당 개수(예: 40~80개), 추출 방식(공간 격자 균등 + 1.0 특징 군집별 층화)을 정하고, 영역 하나를 HoVer-Net 환경에서 돌린 결과를 오버레이로 확인합니다.
- 시간 측정: 다운로드, 타일링, 임베딩, HoVer-Net 영역당 시간을 재서 전체 일정을 계산합니다. 여기서 HoVer-Net 영역 수가 최종 결정됩니다.
- 출력: 확정 파라미터를 config.yaml에 기록, 파일럿 그림.

run_03_download_embed10.py — 생산자 + 1.0 임베딩 (1.0 환경)
- 우선순위 순서로 슬라이드를 받아 queue_svs에 넣습니다. 대기 svs가 상한(예: 15장)에 도달하면 소비자들이 처리할 때까지 기다립니다.
- 슬라이드마다: 메타 저장(MPP, 배율, 크기, 스캐너 벤더) → 썸네일·조직 mask 저장 → MPP 정규화 타일링 → 1.0 임베딩 → HoVer-Net용 영역 좌표 선정 및 저장 → status json에 "embed10 완료" 기록.
- h5 내용: features(float16으로 저장해 용량 절반), coords_level0, coords_um, mpp_original, mpp_target, read_px, tile_px, mag_source(실측/추정), 실패 타일 수, 처리 시간, 파이프라인 버전.
- 모든 소비자가 완료한 svs만 지우는 정리 기능과 --status 모드(단계별 완료 수, 대기열 크기, 실패 목록)를 포함합니다.

run_04_hovernet_regions.py — 소비자: HoVer-Net (TIAToolbox 환경)
- queue_svs에서 "embed10 완료 & hovernet 미완료" 슬라이드를 찾아, run_03이 저장한 영역 좌표에 대해서만 HoVer-Net을 돌립니다.
- 핵 단위 저장(parquet): 중심 좌표(레벨0 픽셀, µm), 종류, 종류 확률, 면적, 장·단축, 이심률, solidity, 둘레(모두 µm 단위), 평균 헤마톡실린 강도, 간단한 질감 지표, 소속 영역 ID.
- 검토용 이미지: 영역 일부의 저해상도 원본과 HoVer-Net 오버레이를 PNG로 저장합니다. svs가 지워진 뒤에도 병리 검토를 할 수 있게 하는 장치입니다.
- 완료 시 status에 "hovernet 완료" 기록, 영역당 처리 시간 로그.
- run_05_embed25.py — 소비자: EXAONEPath 2.5 (2.5 환경, 선택)
- 같은 svs에서 2.5의 patchfy → patch feature → slide embedding을 저장합니다. 2.5 비교를 계획한다면 이 시점에 같이 돌려야 재다운로드가 없습니다. 2.5를 쓰지 않기로 하면 run_03의 삭제 조건에서 이 소비자를 빼면 됩니다.

06_processing_qc.ipynb — 처리 결과 점검
- 슬라이드별 타일 수, MPP·배율 분포(실측/추정 비율), 실패 목록, 임베딩 통계(NaN, 노름 분포), 기관별로 임베딩이 뭉치는지(UMAP을 기관 색으로 칠해 배치 효과 확인).
- HoVer-Net 상식 점검: 종류별 핵 크기 분포(림프구가 가장 작고 둥근지), 원본 배율별 핵 크기 차이가 MPP 정규화 후 사라졌는지.
- 처리 진행 중에도 반복 실행할 수 있게 만듭니다.

07_labels_assembly.ipynb — 라벨·임상·교란변수 통합
- Thorsson mmc2(LUAD/LUSC 행: Immune Subtype, LF, SF, LISS, IFN-γ, TGF-β, TIL RF, Prolif), TCGA-CDR 생존(OS, PFI), ABSOLUTE 순도·배수성, GDC 임상(흡연 상태, pack-years, 병기, 나이, 성별)을 환자 단위로 통합합니다.
- RNA: STAR-Counts를 받아 BRCA 07b의 ESTIMATE 계산을 함수로 옮겨 전체 환자에 적용합니다(메틸화와 독립인 외부 기준).
- 출력: labels/patient_table.csv, 변수별 출처·결측 요약.

08_methylation_labels.ipynb — 메틸화 라벨 6종 (실험 1)
- 450K beta 다운로드, 환자당 1개 규칙 명시, QC(결측 probe 제거, SNP 인접·교차반응·성염색체 probe 제거).
- 라벨: (a) LF 연속값, (b) LF 중앙값 이진, (c) LF 상·하위 삼분위 이진, (d) 분산 상위 probe KMeans k=3(BRCA 방식, 비교 기준), (e) 면역세포 특이 CpG만으로 만든 군집, (f) reference 기반 디컨볼루션 면역 비율(EpiDISH reference를 Rscript로 CSV 내보내기, 추정은 Python 비음수 제약 회귀).
LUAD와 LUSC는 따로 처리합니다.
민감도용: (d)(e)를 fold 안에서 학습하고 test는 최근접 중심에 배정하는 버전(09의 분할이 나온 뒤 다시 실행하는 셀로 분리).

09_splits.ipynb — 분할 고정
- 환자 단위 + site-aware(TSS를 그룹으로 하는 StratifiedGroupKFold) 바깥 5-fold, 그 안의 안쪽 fold까지 미리 생성해 저장합니다. 작은 기관 묶음 규칙을 명시합니다.
- 타깃 종류별(이진, 연속)로 분할 파일을 따로 만들고, 모든 노트북은 이 파일만 읽습니다.
- assert 검증: 환자·슬라이드가 train/test에 동시에 나오지 않는지, 기관이 갈라지지 않는지.

10_label_sanity.ipynb — 라벨이 무엇을 반영하는가
- 라벨 6종끼리의 상관, 각 라벨과 RNA ESTIMATE의 상관, 순도·흡연·병기·Immune Subtype과의 교차표, (d) 군집을 순도로 예측하는 AUROC.
- 판정 규칙을 미리 문서화합니다(예: 순도와 강하게 상관된 라벨은 이후 반드시 순도 통제 분석과 함께 보고).

11_linear_probes.ipynb — 실험 1 본분석, 실험 3a
- pooling: mean, max, mean_std, 내적 attention, top-k mean(라벨과 무관한 기준으로 상위 타일 선택).
- 환자 단위 집계, 중첩 CV로 C·α 선택, 라벨 6종 × pooling 비교표에 외부 타당성(RNA ESTIMATE, 생존과의 연결)을 나란히.
- OOF 예측값을 저장해 17·21에서 재사용합니다.

12_abmil.ipynb — 학습형 MIL (실험 3b~d, f)
- ABMIL(tanh, gated), 헤드는 분류·회귀, 손실은 CE·MSE·Balanced MSE, top-k 변형.
- 학습 시 슬라이드당 타일 무작위 부분추출, 평가 시 전체. float16 특징을 memmap 캐시로 변환해 빠르게 읽습니다.
- 5개 fold 모델 중앙값 앙상블 기록, 슬라이드별 attention 점수를 좌표와 함께 저장(18에서 재사용).

13_prototype_pooling.ipynb — 형태 원형 요약 (실험 3e, 선택)
- fold 안에서 GMM 원형을 학습해 슬라이드를 원형 비율·평균으로 요약, 선형 모델로 평가.

14_exaonepath25_probe.ipynb — 2.5 비교
- run_05 결과의 slide embedding에 같은 분할·환자 집합으로 선형 모델.
- 첫 셀에 2.5 사전학습 데이터에 TCGA 폐암이 포함되었는지 확인한 내용을 기록하고, 포함 시 결과를 참고치로 표시합니다.

15_cell_features.ipynb — 세포 구성과 다형성 4종 (실험 4a·4b)
- 4a: 영역·환자 단위 핵 종류 비율과 밀도.
- 4b: ① 전체 핵 혼합 흩어짐, ② 종양 핵만 슬라이드 전체, ③ 종양 핵만 영역 평균, ④ 종양 핵만 상위 영역(top-1, 상위 5%, 10%). 영역은 종양 핵 30개 이상만, 지표는 표준편차·IQR·변동계수.

16_cell_vs_methylation.ipynb — 실험 4 본분석
- HoVer-Net 염증세포 비율 vs 메틸화 LF·디컨볼루션 비율, 선형 모델 성능을 11·12와 같은 분할에서 비교.
- 다형성 가설: H1(① 상관이 염증세포 비율 통제 후 사라지는가), H2(④가 LF보다 Prolif와 더 강하게 연관되는가).
- 불일치 환자 목록을 만들고 run_04가 저장한 검토 이미지로 확인할 체크리스트를 생성합니다.

17_confounding.ipynb — 실험 2 본분석
- WSI로 순도 예측 성능, LF 예측의 편상관(순도, 다형성 ④, 흡연 각각 통제), 순도 층별 성능, 잔차화 라벨 재예측.
- "통제 전 → 통제 후" 요약표 한 장으로 정리합니다.

18_spatial_features.ipynb — 실험 5 특징
- 영역 세포 구성으로 규칙 기반 영역 유형(종양 우세, 기질 우세, 면역 우세, 혼합) 지정.
- 종양 영역 내 대 기질 영역 림프구 밀도 비, 림프구–종양세포 거리 분포, 면역 한랭 영역 비율, 림프구 군집(TLS 후보), 종양-기질 비율, 다형성 ④와 림프구 밀도의 영역 간 상관.
- 12의 attention 점수를 영역에 매핑해 높은 attention 영역의 세포 구성 표.
- 영역 샘플링 기반이라는 한계를 결과에 명시합니다.

19_survival.ipynb — 실험 5 본분석
- TCGA-CDR 권고에 맞는 종점 선택, 벌점 Cox 4단계(임상 → +메틸화 LF → +공간 특징 → +다형성 ④), 우도비 검정, 교차검증 C-index와 bootstrap CI, 단변량은 BH 보정.
