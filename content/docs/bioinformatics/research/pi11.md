pooling 4가지 중 성능이 제일 좋은 mean_std만 돌려본다. (벡터 길이: 1536)

print(d.shape)

데이터셋 d는 (slide_id, patient, immune_subtype) + 슬라이드 벡터(1536개 feature) + mmc2(PAM50, 점수)를 하나로 합친 데이터이다. 예측하고자하는 라벨은 immune_subtype이다.

```python
feat_cols = [c for c in d.columns if c.startswith("f") and c[1:].isdigit()]
X = d[feat_cols].values.astype(np.float32)
y = d["immune_subtype"].values
CLASSES = sorted(set(y))

maj = pd.Series(y).value_counts(normalize=True)
baseline_acc = maj.iloc[0]
baseline_f1 = 1 / len(CLASSES)
print(f"최빈 클래스({maj.index[0]}) 정확도 기준선: {baseline_acc:.3f}")
print(f"무작위 macro-F1 기준선(≈1/{len(CLASSES)}): {baseline_f1:.3f}")
```
```plain text
최빈 클래스(C2) 정확도 기준선: 0.362
무작위 macro-F1 기준선(≈1/5): 0.200
```

성능 평가 baseline은 두가지인데, 전부 가장 많은 아형인 C2로 찍었을때 정확도(최빈 클래스 정확도)랑 5지선다를 랜덤으로 찍었을때(무작위 macro-F1, 여기서는 1/5)의 F1을 기준으로 성능을 평가한다.

```python
cv = StratifiedKFold(5, shuffle=True, random_state=42)
P = cross_val_predict(make_clf(), X, y, cv=cv, method="predict_proba")
pred = np.array(CLASSES)[P.argmax(axis=1)]

print(f"accuracy {accuracy_score(y, pred):.3f} | macro-F1 {f1_score(y, pred, average='macro'):.3f}\n")
cm = pd.DataFrame(confusion_matrix(y, pred, labels=CLASSES), index=CLASSES, columns=CLASSES)
cm["재현율"] = (np.diag(cm[CLASSES].values) / cm[CLASSES].sum(axis=1)).round(2)
print("[혼동행렬] 행=정답, 열=예측")
print(cm.to_string())

print("\n[아형별 성능]")
print(classification_report(y, pred, digits=3))

ovr = {c: roc_auc_score(y == c, P[:, i]) for i, c in enumerate(CLASSES)}
ovr_macro = roc_auc_score(y, P, multi_class="ovr", average="macro")
print("[아형별 one-vs-rest AUROC]")
for c, v in ovr.items():
    print(f"  {c}: {v:.3f}")
print(f"  macro 평균: {ovr_macro:.3f}")
```

정확도 0.434, macro-F1 0.333이 나왔는데 정확도는 baseline 0.362와 크게 차이가 없고 아형마다 고르게 맞히는지를 보는 macro-F1도 0.200보다 약간 크지만 성능은 낮다.

아형별 one-vs-rest AUROC 평균도 0.651으로 낮다.

confusion matrix를 보면 C3이 그나마 높고 C1과 C2 사이 혼동이 가장 높다.

C1과 C2의 면역 특징은 각각
- C1: wound healing - TGF-β와 증식이 중간, 림프구 침윤은 약간 낮음
- C2: IFN-γ dominant - IFN-γ 반응(1.22)과 림프구 침윤(0.71)이 가장 높고, 증식도 가장 높음(0.41)

인데 두 subtype 모두 증식이 활발한 종양이 많아 겉모습이 비슷하고 / 두 subtype의 차이인 IFN-γ 반응은 분자 수준의 신호라 사진에서 신호를 포착하기 어려워서일수있다. 

정확도가 그나마 높은 C3를 확인해보면 C3의 77%(133/172)가 TCGA subtype이 luminal A인데, luminal A는 분화가 잘 되고 증식이 느린 순한 종양이다. 
그래서 C3 AUROC가 가장 높은 것은 모델이 면역 특성보다 "종양이 얼마나 순하게 생겼나"로 C3를 잘 맞힌걸수도 있다.

```python
dp = d[d["TCGA Subtype"].notna() & (d["TCGA Subtype"] != "BRCA.Normal")]
Xp, yp = dp[feat_cols].values, dp["TCGA Subtype"].values
acc_p = cross_val_score(make_clf(), Xp, yp, cv=cv, scoring="accuracy").mean()
f1_p  = cross_val_score(make_clf(), Xp, yp, cv=cv, scoring="f1_macro").mean()
print(f"WSI → PAM50 (n={len(dp)}, 4클래스): accuracy {acc_p:.3f} | macro-F1 {f1_p:.3f}"
      f"  (최빈 기준선 {pd.Series(yp).value_counts(normalize=True).iloc[0]:.3f})")

oh = pd.get_dummies(d["TCGA Subtype"].fillna("NA")).values.astype(float)
acc_o = cross_val_score(make_clf(), oh, y, cv=cv, scoring="accuracy").mean()
f1_o  = cross_val_score(make_clf(), oh, y, cv=cv, scoring="f1_macro").mean()
print(f"PAM50 단독 → immune subtype: accuracy {acc_o:.3f} | macro-F1 {f1_o:.3f}  (무작위 F1 ≈ {baseline_f1:.2f})")
```
```plain text
WSI → PAM50 (n=819, 4클래스): accuracy 0.663 | macro-F1 0.534  (최빈 기준선 0.537)
PAM50 단독 → immune subtype: accuracy 0.276 | macro-F1 0.210  (무작위 F1 ≈ 0.20)
```

wsi -> immune subtype 맞히기에 tcga subtype, 즉 pam50이 끼어있는지를 확인하려면 다음 두 예측 성능을 보면 된다: wsi -> pam50 맞히기, pam50 -> immune subtype 맞히기.

확인해본 결과 wsi -> pam50은 정확도 0.663으로 모두 LumA로 찍었을때의 F1인 0.537과 크게 다르지 않다. macro-F1은 0.534로 위의 0.333보다 높게 나왔다.

pam50 -> immune subtype은 macro-F1 0.210으로 무작위 수준이다. 즉 사진이 pam50만 보고 면역 아형을 맞혔다까지는 아니고, 
다만 사진으로 잘 볼수있는 축이 분화와 증식이고 그래서 면역 아형 중 그 축과 겹치는 부분(C3, 일부 C4)만 성능이 높았던걸로 볼수있다.
