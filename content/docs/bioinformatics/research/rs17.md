# 폐암 데이터 확인 (01~04)

#2026-10-27

---

TCGA 폐암 데이터를 확인하는 01~04번 파일을 돌려봤다. 

### 01_inventory

```plain text
        slides  svs_ok  embedded
cancer                          
LUAD       404     404       403
LUSC       347     347       347
```

LUAD는 이미지 404장, LUSC는 347장이다. 

이미지 전처리를 (나름) 해서 exaonepath 1.0으로 임베딩해줬었는데 유효한 타일이 하나도 없는 파일이 하나 있어서 (`TCGA-44-7661-01Z-00-DX1`) 1장 빼고 750장이 임베딩됐다.

### 02_cohort

```plain text
        slides  included  tss  no_fold
cancer
LUAD       404       403   33        0
LUSC       347       347   34        0
```

임베딩해놓은 750개는 LUAD 33개 기관, LUSC 34개 기관의 데이터이다.

fold는 모델 input에 사용하려고 분리한 배치인데 모든 데이터가 분할 데이터에 잘 들어가있고

<img width="2100" height="1050" alt="fold_by_tss" src="https://github.com/user-attachments/assets/16ba01a0-769d-4c5f-b338-6a8315cf4959" />

분배를 보면 한 기관은 하나의 fold에 모두 속해있다. 기관에 따른 변동성은 잡음인데 이렇게 넣었을때도 성능이 좋으면 기관 잡음에 강건한 모델이라는게 된다.

### 03_gdc_inventory

```plain text
layer             CNV   DX  MAF  Meth450  Meth_other  RNA  RPPA  TS_BS  miRNA
cancer in_cohort
LUAD   False      117   75  161       55         128  114    86    119    112
       True       402  403  398      403          49  403   279    387    401
LUSC   False      157  131  149       23         133  154    90    157    145
       True       347  347  341      347           0  347   238    331    343
```

WSI에 붙어있는 다른 오믹스 데이터인데 DX, RNA, 메틸화(Meth450)는 모두 있는 샘플만 골랐고 CNV, MAF, miRNA는 일부가 없다. RPPA는 단백질 데이터인데 이게 제일 loss가 많다.

```plain text
                   slides  patients  tumor  lymph
cancer slide_type
LUAD   BS             227       189    219    100
       DX             449       403      0      0
       TS             405       373    392    239
LUSC   BS             146       136    142     58
       DX             360       347      0      0
       TS             324       316    308    206
```

wsi에서 종양%, 림프구침윤% 판독 데이터인데, DX는 없고 BS와 TS만 존재한다. 분석에 DX만 쓸거여서 이 데이터는 없는 데이터지만 추후에 DX wsi로 예측한 TIL과 BS/TS의 TIL을 비교해서 검증 용도로 사용할수있다.
