# wsi모델 연구 정리

#2026-10-22

---

1. introduction

wsi를 딥러닝 모델로 분석할 때는 mil(다중 인스턴스 학습)이 많이 쓰인다. 

mil은 wsi를 패치로 자르고 -> 사전학습 모델로 패치의 특징을 추출 -> 집계해서 wsi 수준 특징을 만드는 과정이다.

그래서 mil 모델의 성능은 사전학습 추출기와 집계기에 달려있다. 

사전학습 추출기로는 pfm(병리 파운데이션 모델)이 사용되는데 HIPT, UNI 등이 있다. 

pfm이 없던 시기에는 ImageNet 사전학습된 ResNet이 특징 추출기로 쓰였었는데 최근에는 (지도학습은 어렵지만) ssl(자기지도학습) 기법으로 pfm을 만들었다고 한다.

2. background

mil 모델을 ssl 기법으로 학습시킨다. ssl은 레이블 없는 데이터에 사용되는 기법인데 원래 이미지를 변형한 이미지를 생성하고 그 이미지의 pseudo label을 생성한 후, 예측 label을 뽑은것과 비교하는 방법으로 학습한다.

ssl로는 대조학습, 자기증류, 마스크 이미지 모델 등이 있다.

3. 추출기와 집계기

mil은 패치 분할 -> 특징 추출 -> 특징 집계 단계로 구성되며 성능은 주로 추출기와 집계기 성능을 따른다.

mil을 3가지로 분류할수있는데 1) 추출기 중심 2) 집계기 중심 3) 하이브리드 중심으로 나눌수있다.

추출기 중심 모델은 패치에서 특징을 뽑을때 변화를 준것이고, 집계기 중심 모델은 특징 추출기는 동결하고 슬라이드 수준으로 집계할때 변화를 준것이다. 

하이브리드 중심 모델은 추출기와 집계기를 모두 사전학습하는 것이다. 

4. 집계기 사전학습

사전학습에는 지도학습과 ssl이 있다. wsi 연구에서는 대부분 ssl을 사용한다.

ssl은 비전 전용 방법과 모달간 방법이 있는데, 비전 전용 방법으로는 대조학습, 마스크 이미지 모델링, 자기 증류 이렇게 3가지를 주로 쓴다고 한다.

모달간 방법은 단일모달 인코더를 사전학습한 다음에 대조학습을 사용해 교차모달정렬을 수행하는 다단계 사전학습을 주로 쓴다.

5. 모델 설계

모델 설계는 아키텍처, 파라미터 수, 규모를 의미한다.

아키텍처는 먼저 추출기와 집계기로 구성되는데 추출기 아키텍처는 1) resnet 같은 cnn 기반 2) vit 3) cnn 통합 트랜스포머 기반 아키텍처가 있다.

집계기 아키텍처는 abmil 계열, perceiver로 구성된다. 

추출기 아키텍처로는 vit 가 많이 쓰이고 집계기로는 abmil이 많이 사용된다. 그리고 대부분이 ViT-L을 주요 백본으로 사용한다고 한다. 

6. 모델 평가

평가는 슬라이드 수준 평가, 패치 수준 평가, 멀티모달 평가, 생물학적 평가(해석)으로 가능하다. 

슬라이드 수준 평가는 wsi 수준 분류성능, 생존 예측성능, wsi 분할 성능 등을 본다. 패치 수준 평가는 패치를 입력 또는 출력으로 패치 분류, 패치 분할 성능을 본다.
