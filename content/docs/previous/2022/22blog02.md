# 잡소리 일기

1. 어저께까지 과식?까진 아니어도 좀 안일하게 먹었었다. 
- 아침에 배 안고픈데 엄마가 먹자고 해서 먹기
- 간식이 미친듯이먹고싶은건 아니고 그냥 먹고싶은 정도였는데 먹기
- 외식(마카롱&막창, 한우물회&수플레케이크, 피자&빙수 등) 종종 함
- 엄마가 외출 후 빵을 한번씩 가져오면 당연하단듯.. 먹음
  
  그래서 53.2kg까지 봤다가 53.6kg로 정체되엇고 이날의 몸무게랑 상관없이 53.2였던 날이랑 비교했을때 눈바디가 매우 충격적이어서(거의 56kg엿을때랑 같았음) 충격먹고 어제 3시 이후로 저녁은 굶고 -> 오늘 아침 쿠키 두 입 & 까르보불닭 1/5개 & 스프 1/2 그릇 먹고 -> 카페에서 아아마시다가 졸도할것같아서 킷캣 1개 먹고 -> 집에와서 졸도안하기위해 크로와상 1/4개 남아있던거 먹고 -> 저녁에 순살치킨 5조각 먹음. 오늘 아침에 53.1kg였나 53.0인가 그랬는데 내일 52를 볼수있을까? 사실 아침에는 식탐이 크게 없고 밤이되면 뭘너무먹고싶어서 미칠것같은데(아침에 까르보 먹는데도 걍 너무맵다 생각만들었음) 밤에 안먹을수있는 원동력이 100% 다음날 아침을 기대하기 위해서다. 다른 동력은 없음... 근데 적고보니 귀찮음도 동력인것만같네. 아무튼 지금은 시카고피자가 너무 먹고싶다 !! 하지만 내일 몸무게를 기대하기위해 참는다. 아니면 내일을 기대할 것이 없어..

2. 오늘 인강 끝낸다고 내일 컨택할수있을것같지 않은데 어쩌지. 벌써 8월인데 9월이 개학아님? 난 방학에 뭘 한것임?

3. 오늘 김윤지랑 카톡하는데 내가 엄마랑 말할때의 기분을 걔가 느낄것만 같아... 먼얘기하려는거지 or 아무리 취향차이라도 내 의견이 더 맞는것같아 라든가. 그래서 카톡할때는 좀 기분안좋았는데(내가 별로가되는것같아서) 다시 읽어보니까 그냥 여느 친구의 대화네? 별거없었네

4. 엄마는 내말을 안듣는게 너무너무 열받는다. 오늘 있었던일은, 5시반쯤 배고파서 엄마한테가서 물었다. '저녁에 뭐 먹을거 없으면 그냥 아침에 남은거 데워서 나혼자 먹으려하는데 뭐먹으려하는지?' 엄마는 치킨 시킬려한다함 -> 지금먹냐고 물어봄(늦으면 그냥 나혼자먹게) -> 아빠한테 시키라해야겠다~함 -> 내가 아빠 없다고 함 -> 에? 아빠가 왜 없어. (이미 내 질문은 생각안하고 이생각뿐임) -> 내가 지금시킨다는거면기다리겠다, 지금시키는거냐고 다시 물어봄 -> 일단 아빠한테 전화한다함 -> 전화 -> 전화를기다리고 끊음 -> 내가 다시한번 지금시키는거니까 그냥 안먹고 기다릴게 라고 말함 -> 엄마대답안하고 주문함 -> 주문다했길래 다시한번 내가 지금시키는거니까 기다리겠다고 말함 -> 엄마가 뭐 감바스라도 데워줄까? 물어봄 -> 열받음... 분명 방금 기다리겟다고 말했는데...ㅋㅋㅋㅋ 내 질문 모두 무시 + 그럼에도 불구하고 내 선에서 상황 판단 후 입장 표명했는데 그것도 무시. 걍 본인 할말만 함. 진짜 개열받는다.

5. 오늘 왤케 다 열받지? 오빠 맨날 '내일 뭐뭐 하자~' 해놓고 다음날 그럴생각없엇다는듯 행동하는거 제일 싫다. 나는 약속잡아놓으면 시간배분&기타등등 배분에 그거포함해서 빼놓는데... 외출할거 생각해서 카공안하고 집에있는다거나 집에서 좀 적게 먹는다거나...
